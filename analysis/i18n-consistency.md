# UI 词条一致性验证（2026-10-31）

## 调查结论与修复

- 当前 `src/` 的 TypeScript / Vue 源码中未发现 `map.binding_button`、`station.stats_time`、`ui.total_volume` 的调用。空间站界面实际使用 `station.header_time`、`station.summary_time` 等词条。因此，不能将这三个字典差异直接归因为已发生的页面错误。
- 保留全部已有翻译：英文补充 `station.stats_time`（Total Build Time）和 `ui.total_volume`（Total Volume），简体中文补充 `map.binding_button`（绑定）。12 份 UI 字典现在均有 1541 个叶子键。
- `src/i18n.ts` 使用浅合并 `{ ...uiMsg, ...gameMsg.default }`。两套游戏字典以游戏文本 ID 为键；测试确认它们与 UI 顶层键不冲突，无须改动合并方式。
- 版本切换此前只使当前语言缓存失效，其他已加载语言会继续使用旧版本游戏词条。现在切换版本时清空所有语言的加载标记，按需重新加载。
- 英文 UI 原本同步加载，但英文游戏词条只有选择英文时才加载。现在首次加载非英文语言以及版本切换后的首次加载，都会先准备当前版本的英文游戏词条，保证回退数据可用。
- `changeLanguage()` 此前在加载器回退到英文后，再次选择原本加载失败的语言。现在直接保留加载器返回的语言结果。

## 自动检查范围

`tests/unit/current/i18n/ui-locales.spec.ts`：

- 自动发现全部 12 份 UI JSON，以英文为基准检查完整键集（包括缺项和额外项）。
- 检查每个词条的插值参数一致性，保留现有有意留空的词条。

`tests/unit/current/i18n/game-folder-i18n.spec.ts`：

- 对 12 种语言执行 8.0 → 9.0 → 8.0 切换；每次对比完整的 UI 与游戏消息合并结果，并验证实际 `t()` 解析，包括本次补齐的三个键。
- 切换版本前先选英文，覆盖其他语言处于非活动缓存中的情形。
- 对 11 种非英文语言模拟缺失 UI / 游戏词条，验证英文回退及英文消息与当前游戏版本一致。这是缺项模拟，不代表发布数据实际缺少这些游戏词条。
- 验证不支持的语言回退到英文。
- 保留繁体中文、日语浏览器语言识别、Cookie 优先级和 9.0 英文特有游戏词条的已有测试。

回归证据：将扩展后的加载测试指向修改前加载器的临时副本，得到 23 项失败、12 项通过；临时副本已删除。

## 验证结果与边界

- i18n 定向单元测试：48 项通过。
- 完整单元测试：`NODE_OPTIONS=--no-experimental-webstorage npm run test:unit`，200 个文件通过、3 个跳过；1268 项测试通过、15 项跳过。
- 当前环境使用 Node 26；直接运行 `npm run test:unit` 曾有 232 项失败，日志显示实验性 localStorage 未提供可用存储对象。关闭该实验选项后完整套件通过；未为此修改业务代码或测试基础设施。
- `npm run build` 通过，包含生产兼容检查、TypeScript 检查和 Vite 构建；仍有资源包超过 500 kB 的体积警告。
- 未运行浏览器 E2E 或人工浏览器检查。尚未验证真实浏览器中的语言选择器交互、版本切换后的页面更新、Cookie 持久化、字体、长文本截断及排版；jsdom 测试不替代这些检查。

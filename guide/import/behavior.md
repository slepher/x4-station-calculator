# Import Behavior

## 第一章：操作定义

- `guide.import.select-file`
  - `action`: 选择 JSON 文件。
  - `expected`: 文件名显示，且导入配置区域可见。
- `guide.import.select-mode`
  - `action`: 选择覆盖或增量模式。
  - `expected`: 当前模式高亮切换到被点击项。
- `guide.import.toggle-module`
  - `action`: 勾选/取消模块项。
  - `expected`: 对应模块勾选状态发生变化。
- `guide.import.apply`
  - `action`: 点击应用导入。
  - `expected`: 导入执行完成并关闭导入弹窗。

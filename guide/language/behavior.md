# Language Behavior

## 第一章：行为定义

- `guide.language.switcher`
  - `type`: `action`
  - `index`: `guide.language.switcher`
  - `action`: 在语言下拉框中选择目标语言。
  - `expected`: 语言切换成功，界面文本更新为所选语言。
  - `data`:
    - `control`: `select`
    - `options`:
      - `en`: `English`
      - `zh-CN`: `简体中文`
      - `zh-TW`: `繁體中文`
      - `de`: `Deutsch`
      - `fr`: `Français`
      - `it`: `Italiano`
      - `es`: `Español`
      - `ru`: `Русский`
      - `ja`: `日本語`
      - `ko`: `한국어`
      - `pt-BR`: `Português (Brasil)`
      - `pl`: `Polski`

# 实施任务

每个行为任务在同一实现步骤中完成并运行 tests/unit/processor 下的定向 Unit，不另设测试实现阶段。

## 1. 目标和执行计划

- [x] 1.1 实现 all、单项、多项及旧入口名称归一化；更新帮助。Unit 覆盖公开目标、空/未知/重复目标、别名重复、all 互斥及缺少目标。
- [x] 1.2 基于实际字段依赖定义固定阶段、目标归属和保存集合，统一阶段结果；Unit 覆盖共享依赖一次执行、隐式依赖不扩大写入范围和 fresh version state。
- [x] 1.3 将版本、路径和模型参数校验改为基于执行计划；Unit 覆盖 all/all-versions 区分、输出隔离、资源专用选项、sector 仅限单目标、8.0/9.0 参数差异及显式输入错误。

## 2. 按目标构建与保存

- [x] 2.1 拆分 loader 混合构建及 save，覆盖 design 表中全部实体、类型、DLC、消费和基础资源目标；复用原算法。Unit 覆盖各公开目标空目录独立执行、关联产物完整、隐式依赖不写出和未选文件不变。
- [x] 2.2 接入派系、改造星球、研究和蓝图扩展的按需计算与保存。Unit 覆盖依赖准备、名称及引用保持、独立扩展与整体对应结果一致。
- [x] 2.3 实现整体语言重建、局部合并和独立 languages，更新语言清单及既有英文名称注入。Unit 覆盖无关翻译保留、完整名称收集、确定性排序、独立 languages 不写实体、目标顺序不影响结果。

## 3. 地图资源统一流程

- [x] 3.1 分离地图计算与持久化，向统一流程提供本轮地图、定义和区域输入。Unit 覆盖 maps 不写派系/资源副文件、空目录自动依赖和指定输入覆盖。
- [x] 3.2 资源计算消费本轮结构或明确外部输入，统一 resourceareas 最终归属，并接入 all。Unit 覆盖 all 使用新地图、资源副文件唯一写入、map-resources 不写 maps/factions、两模型完整输出。
- [x] 3.3 保留星区增量、版本逐格缓存、强制重算和存档规则。Unit 覆盖其他星区及缓存不变、损坏缓存处理、模型适用性和非法 sector 组合。
- [x] 3.4 统一阶段与版本日志、输出汇总和失败停止。Unit 覆盖阶段失败标识、非零退出码、后续阶段及版本未执行，旧名称进入同一流程。

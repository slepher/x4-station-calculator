# 统一数据处理流水线

## 目标

重构现有 TypeScript processor，使同一入口既能迁移指定类别的数据，也能一次完成一个版本的全部数据迁移。地图资源计算属于整体迁移的一部分，不再要求用户另行执行资源命令。

## 已确认方案（审核重点）

### 入口与选择

- `npm run process -- all` 迁移配置当前版本的全部数据；`all --all-versions` 按配置顺序迁移全部版本。
- 支持单项与逗号分隔多项，例如 `wares`、`ships,equipments`、`map-resources`。目标是数据类别，不是任意单条实体；地图资源继续支持 `--sector` 星区级更新。
- 数据类别覆盖现有 processor 全部产物。`res.json` 是基础资源资料，命名为 `resource-info`；`map-resources` 是星区资源储量、刷新率和逐格计算，避免二者混淆。
- 原命令 `data` 归一化为 `all`，补齐地图资源；`map` 归一化为 `maps`；`resources` 归一化为 `map-resources`。它们只作为入口名称，不保留独立流水线。
- 未知、空、重复目标报错；`all` 不可与其他目标组合。保留版本、flavor、输出目录和现有适用的路径覆盖能力。

### 依赖与流程

- 使用固定依赖关系及执行顺序，同一版本内公共依赖只计算一次，每个版本使用新的运行状态。
- 整体流程包含基础数据、扩展数据、地图、地图资源、语言及名称收尾。资源计算自动使用本轮生成的地图和资源定义，不读取旧输出代替本轮结果。
- 单项任务自动从原始输入准备必要依赖，即使输出目录为空也能运行；显式指定已有地图等输入时使用指定输入，缺失或无效则报错，不自动切回默认输入。
- 必要依赖可以在内存中计算，但不得因此写出未选择的数据类别。对需要关联持久化的派生产物，必须在目标归属中明确列出。

### 输出与保存

- 将计算与写入分开，替代当前统一 `save()` 全量写出方式。每个产物有明确写入责任。
- `resourceareas.json` 的最终产物由地图资源阶段负责，地图解析仅提供计算输入。整体执行不重复写出不同阶段的同名中间产物。
- 单项迁移只更新目标、归属的派生产物和所需语言条目，未选择的 JSON 文件保持原内容。独立地图更新不隐式更新派系或地图资源文件。
- 局部语言更新合并本轮收集到的条目，保留其他类别的翻译；整体迁移重新生成完整语言包。独立 `languages` 目标收集全部类别名称并重建语言包，不写其他数据。
- 保留现有文件名、JSON schema、数值计算、数组顺序与名称解析行为。整体产物应等价于现有 TS `data` 加 `resources` 顺序执行的最终结果。

### 资源模型与异常

- 保留 8.0 regions、9.0+ resourceareas 模型、版本缓存隔离、强制逐格重算和存档样例的现有适用规则。
- `--sector` 仅允许唯一目标 `map-resources`，不能让整体或多项迁移悄悄变成部分资源更新。更新时保留其他星区产物与缓存。
- 资源专用选项仅在执行计划含地图资源计算时适用，模型不支持的选项仍报错。
- 无效目标、参数冲突和版本选择错误在执行前报错。运行失败报告版本与阶段并停止，不宣称成功；不引入跨文件事务或自动回滚。

## 边界

### In Scope

TS CLI、版本上下文、固定依赖调度、loader 计算边界、按目标保存、地图与资源衔接、语言保存、帮助与使用文档、定向 Unit 和构建验证。

### Out of Scope

修改资源算法或游戏数据 schema；Vue/store/presenter 改造；Rust/WASM 构建；单条 ware/entity 编辑；并行调度、插件框架、通用 DAG 引擎、跨文件事务；清理旧 Python；提交、合并、发布及归档旧 migrate change。

## 验收标准（DoD）

1. 空输出目录执行一次 `all`，生成原 data 与 resources 的完整最终产物，包括 `map_resources.json`，8.0 和 9.0 均通过精确对照。
2. 所有公开目标可以单独执行；必要依赖自动准备，不要求先执行其他命令。独立结果与相同输入的整体迁移对应产物一致。
3. 单项和多项更新不覆盖无关 JSON；公共依赖只计算一次；共享语言不会丢失未选类别的条目。
4. `maps` 不修改地图资源产物；`map-resources` 不修改 `maps.json` 或派系。整体迁移只使用本轮地图依赖，资源副文件拥有唯一最终写入责任。
5. 单星区更新保留其他星区资源与缓存；两种模型的参数规则和版本隔离继续有效。
6. `all`、`--all-versions` 语义独立，组合时每个版本都完成完整迁移；失败停止并准确报告。
7. 旧入口名称按上述规则进入统一流程，帮助文档明确 data 现在包含资源计算；参数冲突及无效输入返回非零退出码。
8. 行为任务附带 `tests/unit/**` 定向覆盖；完成实现后 `npm run build` 通过。

## 未决项

无。目标目录及关联产物映射在 design 中展开，不改变上述执行与保存边界。

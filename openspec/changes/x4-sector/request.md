# x4-sector 需求说明（最终实现态）

## 目标
在“星区总览”模式下提供可用的星区管理与补给站视图能力，且不改动现有模块主命名。

## 当前范围

### 1. 星区管理
- 支持创建任意数量星区。
- 支持重命名、删除、排序星区。
- 支持将空间站拖拽分配到目标星区。
- 新建空间站默认进入“未分配空间站”。

### 2. 拖拽与顺序
- 星区支持拖拽排序（移动语义）。
- 空间站支持拖拽移动到星区或未分配区。
- Tab 取消拖拽排序，顺序由“星区顺序 + 星区内站点顺序”驱动。

### 3. 补给站入口与页面
- 每个有空间站的星区在 Tab 上显示一个虚拟补给站入口。
- 点击补给站 Tab 进入整页补给站视图（不是右侧局部面板）。
- 点击总览 Tab 返回总览页面。
- 补给站页面三栏布局：
  - 左栏：建筑区（占位）
  - 中栏：资源视图（复用帝国资源视图组件）
  - 右栏：建造材料区（占位）
- 三栏宽度比例与主站点视图一致：`3 / 5 / 4`，`gap-8`。

### 4. 资源统计口径
- 星区总览资源视图：统计当前 empire 全部空间站。
- 补给站资源视图：仅统计该补给站所属星区内的空间站。
- 资源视图 UI 与交互完全复用帝国资源视图（数量/经济切换、分组样式一致）。

### 5. Store 层内部计算
- `useEmpireStore` 中独立计算全部星区内部数据，并保存为 `Map`。
- 每个星区包含：
  - 规划输入（本地站点 ID 等）
  - 本地聚合流量（用于补给站资源视图）

### 6. 版本与兼容
- Empire 存储版本升级为 `4`。
- 旧数据迁移、导入导出按当前最终结构执行。

## 明确不做
- “星区连接（link）”功能已在开发中途取消，当前版本不提供（UI 与 store 操作均已关闭）。
- 补给站建造区与建造材料区暂不接入真实业务逻辑（占位）。

## Context

新增“船只建造”视图，需保持与现有“量化生产”一致的页面结构与视觉风格，并在缺少计算逻辑时先完成布局与筛选入口。

## Decisions

1. **视图层级**：与“量化生产”“逻辑组网”同级，沿用同一套切换入口。
2. **按钮组复用**：顶部“新建/保存/载入”按钮组复用位置与结构，仅切换为绿色系主题。
3. **布局策略**：上部筛选 + 下部三列占位布局；三列风格与“量化生产”一致。
4. **筛选规则**：`class` 必选，`race`/`type` 至少选一个才能显示列表。
5. **联动规则**：`type` 选项按 `class` 联动过滤；`race` 与 `type` 同时选择时取交集结果。
6. **数据来源**：飞船定义与筛选数据来自 `types/x4.ts`。
7. **名称本地化**：飞船列表名称通过 `x4i18n` 进行翻译，新增类型需补充对应处理逻辑。
8. **计数标签**：`race` 标签显示当前 `type` 选择下的数量；`type` 标签显示当前 `race` 选择下的数量。

## Non-Goals

- 不实现配装、属性或材料计算逻辑。
- 不提供复杂的飞船详情展示或高级筛选。

## Risks

- 过滤条件较多，若 UI 信息层级不清晰可能导致选择成本升高。
- 后续接入计算逻辑时需要确认占位区结构是否足够承载扩展内容。

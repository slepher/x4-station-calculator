# 需求说明：船只建造视图

## 目标
新增与“量化生产”“逻辑组网”同级的“船只建造”视图，提供飞船筛选与列表展示入口，并先完成布局与基础筛选逻辑，后续再接入配装/属性/材料计算。

## 已确认方案（审核重点）
1. **入口与层级**
   - “船只建造”与“量化生产”“逻辑组网”同级，使用同一套切换入口。

2. **顶部按钮组主题**
   - 复用现有“新建/保存/载入”按钮组的位置与结构。
   - 按钮视觉主题切换为绿色系。

3. **页面布局**
   - 上下分区：上部为“选择船只”，下部为三列布局。
   - 下部三列：左“配装”、中“配装后船体属性”、右“建造材料”，全部为占位结构，不填充内容。
   - 三列 UI 风格与“量化生产”保持一致。

4. **飞船筛选维度与显示规则**
   - 维度：`class`（大小，4 个选项，必选）、`race`（约 10 个选项）、`type`（约 10 个选项）。
   - `class` 必选；若未选择 `class`，不显示飞船列表。
   - `race` 与 `type` 至少选择一个；若二者都未选，不显示飞船列表。
   - 当 `class` 已选且 `race` 或 `type` 至少一个已选，才展示飞船列表。
   - 当 `race` 与 `type` 同时选择时，结果按两者交集过滤。

5. **筛选联动**
   - `type` 选项包含 `class: []` 字段，`type` 选项需随 `class` 联动过滤。
   - 数据源来自 `types/x4.ts` 中的飞船定义。
6. **飞船名称 i18n**
   - 飞船列表展示名称需使用 `x4i18n` 的翻译能力进行本地化。
   - 为新增的飞船类型补充 `x4i18n` 处理逻辑，确保名称可翻译。
7. **类型/种族计数标签**
   - `race` 选择标签显示 `名称 (count)`，`count` 表示在当前 `type` 选择下可用飞船数量。
   - `type` 选择标签显示 `名称 (count)`，`count` 表示在当前 `race` 选择下可用飞船数量。

## 边界
### In Scope
- 新增“船只建造”同级视图与入口。
- 顶部按钮组主题切换为绿色系。
- 上部筛选区 UI 与飞船列表的展示/隐藏逻辑。
- `class`/`race`/`type` 的筛选与联动逻辑（含交集规则）。
- 下部三列占位布局与样式对齐。
- 飞船名称 i18n 化展示（通过 `x4i18n`）。
- 类型/种族筛选标签显示计数。

### Out of Scope
- 配装、船体属性、建造材料的计算逻辑。
- 复杂的飞船详情展示或高级筛选。
- 测试自动化落地（若无现有测试基础）。

## 验收标准（DoD）
1. “船只建造”与“量化生产”“逻辑组网”同级可切换进入。
2. “新建/保存/载入”按钮组保持原位置结构，主题切换为绿色系。
3. 页面结构为上下分区；下部三列占位布局完成，风格与“量化生产”一致。
4. `class` 未选时不显示飞船列表。
5. `race` 与 `type` 均未选时不显示飞船列表。
6. `class` 已选且 `race` 或 `type` 至少一个已选时显示飞船列表。
7. `race` 与 `type` 同时选择时，结果按交集过滤。
8. `type` 选项随 `class` 联动过滤，数据源为 `types/x4.ts`。
9. 飞船列表名称使用 `x4i18n` 翻译结果；新增的飞船类型已纳入 `x4i18n` 处理逻辑。
10. `race` 标签显示 `名称 (count)`，`count` 为当前 `type` 选择下的飞船数量。
11. `type` 标签显示 `名称 (count)`，`count` 为当前 `race` 选择下的飞船数量。

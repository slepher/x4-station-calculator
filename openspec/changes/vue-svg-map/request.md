# vue-svg-map 需求说明

## 目标
将地图页从静态 `maps.svg` 图片升级为 Vue 组件动态渲染 SVG，支持在 SVG 内直接交互与 i18n。
保证地图在当前 UI 中具备可控缩放、拖拽与后续扩展能力。

## 已确认方案（审核重点）

### 1. 渲染模式
- 不再以 `<img src="maps.svg">` 作为唯一渲染方式。
- 改为 Vue 组件基于 `maps.json` 动态生成 `<svg>` 图元。
- 地图交互（缩放、拖拽、hover/click 扩展）在 SVG 内实现。

### 2. i18n 显示策略
- 文字显示以 `nameId` 为主键，从当前语言 `locales/*.json` 取值。
- 回退顺序：`locale[nameId]` -> `maps.json.name` -> `nameId`。
- 语言切换时，地图标签应实时更新，不需要重新生成静态 SVG 文件。

### 3. 缩放与拖拽交互
- 地图左下角保留比例尺缩放条。
- 最小缩放：地图宽度适配可视区域宽度。
- 最大缩放：一个 cluster 视觉高度约为半屏高度。
- 鼠标左键按住拖拽平移地图。
- 鼠标滚轮控制缩放，缩放锚点为鼠标当前位置。

### 4. 视图入口与兼容
- 继续使用 Toolbar 第四个 tab（`maps`）作为地图入口。
- `?router=maps` 参数继续可直接进入地图视图。
- 首版需与当前地图视觉风格基本一致（颜色/线型/标签层级）。

### 5. 分阶段替换
- 第一阶段：完成 Vue-SVG 主体渲染和交互，不依赖静态图片文本。
- 第二阶段：按图层补齐细节（cluster/sector/links/stations），并保证可扩展筛选与高亮。

## 边界

### In Scope
- 地图页 SVG 组件化渲染。
- 地图 i18n 文本绑定与实时切换。
- 缩放条、滚轮缩放、拖拽平移与边界约束。
- 现有地图入口与参数兼容。

### Out of Scope
- 地图数据源结构重做（`maps.json` 主结构不在本次重构）。
- 引入新的后端接口或服务端渲染。
- 大规模视觉改版（主题、配色体系重构）。

## 验收标准（DoD）
- 地图由 Vue 组件渲染 SVG，且不依赖静态图片内置文本完成名称显示。
- 切换语言后，cluster/sector 名称即时切换至对应语言。
- 缩放条可用，最小缩放贴合宽度，最大缩放满足 cluster 半屏高度目标。
- 支持鼠标拖拽与滚轮缩放，缩放过程以鼠标位置为锚点，交互连续无明显跳动。
- 保留 `maps` tab 与 `?router=maps` 入口可用。
- 构建通过（`npm run build`）。

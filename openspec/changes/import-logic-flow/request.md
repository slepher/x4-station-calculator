# Request: import-logic-flow

## 目标

在不改动现有导入体系（XML/GameCom）前提下，新增“逻辑组网导入到空间站/帝国”的能力，并确保：

1. 导入前有明确确认。
2. 导入结果可解释（映射规则固定）。
3. 跳过/忽略项有统一 warning 反馈。
4. 默认组名逻辑统一，修复 `group.name` 自动写入偏差。

## 已确认方案（审核重点）

### 1) 入口与布局

1. 空间站页面：导入按钮放在最右侧并右对齐；名称区扩展占位。
2. 帝国总览页面：新增同风格导入按钮，最右侧并右对齐。

### 2) 导入来源

1. 空间站导入：选择“方案 + 规划区”。
2. 帝国导入：选择“方案（全量规划区）”。

### 3) 导入前确认

1. Empire：复用 `SmartSaveDialog`，动作是“保存并导入 / 放弃并导入”。
2. Station：使用独立确认弹窗，动作是“导入为新空间站 / 覆盖当前空间站”。

### 4) 映射规则

1. 仅 `manual` 节点参与导入。
2. `manual` 节点映射到目标站 `plannedModules`，同 `moduleId` 聚合计数。
3. Empire 导入时：每个非空规划区创建一个空间站。
4. Station 导入时：
   - 覆盖当前站：先清空后导入。
   - 导入为新站：创建新站并自动切换。

### 5) 空数据与 warning

1. 空方案：阻止导入。
2. Empire 导入遇到空规划区：跳过，不建站。
3. `isolated` 锁定仅对 `container` 生效；非 `container` 自动忽略。
4. 所有“跳过/忽略”统一汇总为一个 warning 弹窗。

### 6) 保存策略

导入后不自动保存，沿用现有手动保存流程。

### 7) 默认组名与 bug

1. `group.name` 自动写入默认名不是设计意图，按 bug 处理。
2. 默认组名算法抽为通用逻辑，至少在以下位置共用：
   - 规划区标题
   - 紧凑视图标题
   - 方案加载列表组名
3. 统一算法：`group.name` 为空时，取最高 tier 的 `manual` 节点；同 tier 优先非 isolated，再按 `order`。

### 8) 本轮补充确认（导入界面）

1. 帝国导入界面切换为“加载帝国”界面形态，但实现方式为直接改造当前导入模板（不新开一套模板）。
2. 空间站导入界面保持一级菜单为下拉；选中方案后，二级区域仿照帝国导入形态展示该方案下全部可导入规划区。
3. 空间站二级区域自动隐藏空规划区（无 `manual` 节点的规划区不展示）。
4. 空间站二级区域对每个规划区提供“直接导入”按钮（不走先选中再统一继续）。
5. 若方案下无可导入规划区，显示空态提示文案：`该方案下暂无可导入的规划区`。
6. 帝国方案卡片与空间站规划区卡片均保留“详情预览”信息（如更新时间、统计摘要、预览条目与 `+N more...`）。
7. 移除导入弹窗底部“继续”按钮；不使用“选择后再继续”的二段式流程。
8. 导入业务逻辑保持现状，不引入新的映射或执行分支。
9. 二级选择区不新增搜索、分页、排序能力。

### 9) 本轮补充确认（保存弹框判定）

1. 点击导入时，“保存确认弹框”并非总是弹出。
2. 弹框判定逻辑与“新建按钮”逐条件一致。
3. 导入与新建必须复用同一套判定逻辑，禁止重复编写。
4. 若当前判定逻辑位于 Vue 组件层，需上提到 store，由新建/导入共同调用。
5. `activeStationId` 的变化（如站点页切到帝国总览）不应单独触发 dirty；dirty 仅由帝国业务数据变化触发。

## 边界

### In Scope

1. 导入入口调整与新增。
2. 逻辑组网导入选择与确认流程。
3. 映射实现、warning 汇总、默认组名逻辑统一。

### Out of Scope

1. XML/GameCom 导入改造。
2. 逻辑组网拖拽/编辑机制重构。
3. 导入后自动保存。

## 验收标准（DoD）

1. Station/Empire 两侧都能进入逻辑导入流程。
2. Station 新建/覆盖两分支正确。
3. Empire 在“需要保存确认”的条件下复用 `SmartSaveDialog`，且两动作都可完成导入。
4. `manual -> plannedModules` 映射正确，计数正确。
5. 空方案被阻止；空规划区被跳过且不建站。
6. 非 `container` isolated 被忽略并进入 warning 汇总。
7. warning 以单弹窗汇总展示。
8. 导入后不自动保存。
9. 默认组名逻辑统一复用，store 不再自动写 `group.name`。
10. 帝国导入切换为“加载帝国”界面形态（直接改当前模板）且不含删除入口。
11. 空间站导入保持一级下拉；二级区按帝国形态展示可导入规划区，并为每个规划区提供直接导入按钮。
12. 空间站二级区自动隐藏空规划区；若无可导入规划区则显示空态文案“该方案下暂无可导入的规划区”。
13. 帝国与空间站导入卡片都保留详情预览信息（含 `+N more...` 预览扩展提示）。
14. 导入弹窗不再依赖底部“继续”按钮触发导入流程。
15. 二级内容区无搜索/分页/排序。
16. 导入触发保存确认弹框的条件与新建按钮逐条一致；条件不满足时不弹框并直接进入导入流程。
17. 新建与导入复用同一判定逻辑入口（若原在 Vue，已上提 store）。
18. `activeStationId` 变化不引起 dirty；仅切换当前站点/总览不应导致“需要保存确认”。

## 未决项

无。

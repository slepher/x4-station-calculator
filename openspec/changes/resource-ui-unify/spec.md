# Resource UI Unify Specification

## Purpose

本文档定义地图 UI 布局重构的功能规范，包括资源/空间站面板 tab 化、搜索框位置调整、资源颜色数据源切换、yield 下拉框 5 等级改造，以及 tooltip 数字格式化（显示 respawn 值）。

---

## ADDED Requirements

### Requirement: ResourceStationTabUnify

资源面板和空间站面板统一到右下角，采用 tab 切换形式。

#### Scenario: 用户打开资源面板

**前提**：用户在地图页面，资源面板和空间站面板均关闭
**当**：用户点击右下角的「资源」tab 按钮
**那么**：资源面板在左侧展开
**并且**：资源 tab 按钮呈现金色高亮选中状态

#### Scenario: 用户打开空间站面板

**前提**：用户在地图页面，资源面板和空间站面板均关闭
**当**：用户点击右下角的「空间站」tab 按钮
**那么**：空间站面板在左侧展开
**并且**：空间站 tab 按钮呈现金色高亮选中状态

#### Scenario: 用户在资源面板打开时切换到空间站面板

**前提**：资源面板已打开
**当**：用户点击空间站 tab 按钮
**那么**：资源面板关闭，空间站面板展开
**并且**：空间站 tab 按钮呈现金色高亮选中状态，资源 tab 按钮恢复普通状态

#### Scenario: 用户关闭侧栏

**前提**：资源面板或空间站面板已打开
**当**：用户点击侧栏关闭按钮
**那么**：侧栏关闭
**并且**：对应 tab 按钮恢复普通状态，不再高亮

---

### Requirement: SearchBoxRelocation

搜索框从右上角移动到左上角。

#### Scenario: 用户查看地图

**前提**：用户进入地图页面
**当**：页面加载完成
**那么**：搜索框显示在左上角位置

---

### Requirement: ResourceColorFromResJson

资源颜色数据源从 `regionyields.color` 改为 `res.json` 中的 `color_rgb` 字段。

#### Scenario: 资源筛选显示颜色

**前提**：用户选择某种资源进行筛选
**当**：资源面板显示该资源的标签和筛选结果
**那么**：资源颜色使用 `res.json` 中对应资源的 `color_rgb` 值（如 `#FF66FF`）

---

### Requirement: YieldFiveLevels

Yield 下拉框改为 5 个等级，显示等级名称和数值范围。

#### Scenario: 用户查看 yield 下拉选项

**前提**：用户在资源面板选择了一种资源
**当**：用户点击 yield 下拉框
**那么**：显示 5 个选项：
- 低 (<3000)
- 中低 (<10000)
- 中 (<30000)
- 中高 (<100000)
- 高 (<300000)

#### Scenario: 用户选择 N 矿的 yield

**前提**：用户在资源面板选择了 N 矿 (nividium)
**当**：用户点击 yield 下拉框
**那么**：显示 5 个选项（阈值为空间站资源的 1/100）：
- 低 (<30)
- 中低 (<100)
- 中 (<300)
- 中高 (<1000)
- 高 (<3000)

---

### Requirement: TooltipNumberFormat

地图 tooltip 中显示的资源数值使用 respawn 值，并根据数量级格式化显示。

#### Scenario: 用户查看地图 tooltip

**前提**：用户 hover 地图上的 sector
**当**：tooltip 显示时
**那么**：资源数值根据数量级显示：
- < 1：保留 2 位有效数字（如 `0.000045`）
- ≥ 1 且 < 10：保留 2 位小数（如 `9.87`）
- ≥ 10 且 < 1,000：显示整数（如 `123`）
- ≥ 1,000 且 < 1,000,000：保留 2 位小数 + K（如 `12.34K`）
- ≥ 1,000,000 且 < 1,000,000,000：保留 2 位小数 + M（如 `12.34M`）
- ≥ 1,000,000,000 且 < 1,000,000,000,000：保留 2 位小数 + B（如 `12.34B`）
- ≥ 1,000,000,000,000 且 < 1,000,000,000,000,000：保留 2 位小数 + T（如 `12.34T`）
- ≥ 1,000,000,000,000,000：保留 2 位小数 + P（如 `12.34P`）

## MODIFIED Requirements

### Requirement: PanelEntryButtonBehavior

资源/空间站面板的入口按钮行为变更。

**原有行为**：
- 资源按钮位于左上角 (`left-6 top-5`)
- 空间站按钮位于左下角 (`left-6 bottom-5`)
- 打开侧栏时，对应按钮隐藏

**变更后行为**：
- 资源按钮和空间站按钮均位于右下角，水平并排
- 打开侧栏时，对应按钮保持显示
- 当前打开的侧栏对应按钮呈现金色高亮选中状态

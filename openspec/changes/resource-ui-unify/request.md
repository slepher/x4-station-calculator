# Resource UI Unify - 请求文档

## 1. 目标

地图 UI 布局重构：将资源面板和空间站面板统一到左下角，采用切换 tab 形式；搜索框移至左上角；资源颜色改用 `res.json` 中的 `color_rgb` 字段；yield 下拉框改为 5 等级（低、中低、中、中高、高），基于 `maps.json` 中的 `rating` 字段；tooltip 数字根据数量级 (K/M/B/T/P) 格式化显示，数据源改为 respawn。

## 2. 已确认方案（审核重点）

### 2.1 UI 布局变更

| 元素 | 当前位置 | 目标位置 | 备注 |
|------|----------|----------|------|
| 搜索框 | 右上角 (`right-6 top-5`) | **左上角** (`left-6 top-5`) | 保持现有样式 |
| 资源面板按钮 | 左上角 (`left-6 top-5`) | **左下角** (`left-6 bottom-5`) | 与空间站按钮并排成 tab |
| 空间站面板按钮 | 左下角 (`left-6 bottom-5`) | **左下角** (`left-6 bottom-5`) | 与资源按钮并排成 tab |

### 2.2 Tab 设计

- **排列方式**：水平并排
- **按钮文案**：沿用现有 i18n key（`map.resource_filter_button` / `map.station_panel_button`）
- **按钮常显**：打开侧栏时按钮不消失
- **高亮样式**：当前活动侧栏对应按钮呈现金色高亮边框 + 半透明背景（类似 `resource-mode-tab.active`）

### 2.3 资源颜色数据源

- **当前**：从 `regionyields` 读取 `color` 字段（颜色名称，如 `magenta_bright`）
- **目标**：从 `res.json` 读取 `color_rgb` 字段（如 `#FF66FF`）

### 2.4 Yield 下拉框 5 等级

Yield 下拉框显示 5 个等级，等级判定基于 `maps.json` 中资源的 `rating` 字段（1-5）：

| rating | 等级 | 说明 |
|--------|------|------|
| 1 | 低 | 最低产量等级 |
| 2 | 中低 | 较低产量等级 |
| 3 | 中 | 中等产量等级 |
| 4 | 中高 | 较高产量等级 |
| 5 | 高 | 最高产量等级 |

- **显示格式**：仅显示等级名称（如「低」、「中低」），不显示数值阈值
- **数据来源**：`maps.json` 中每个资源条目的 `rating` 字段
- **筛选逻辑**：资源 `rating` >= 选择的等级对应的 rating 值
- **版本范围**：8.0 Diplomacy 和 9.0 Empire 两个版本同步修改

### 2.5 Tooltip 数字格式化

地图 tooltip 中显示的资源数值使用 **respawn 值**（资源再生速度），并根据数量级自动格式化：

| 数值范围 | 显示格式 | 示例 |
|--------|----------|------|
| < 1 | 保留 2 位有效数字 | `0.000045` (输入 `0.000045223`) |
| ≥ 1 且 < 10 | 保留 2 位小数 | `9.87` |
| ≥ 10 且 < 1,000 | 显示整数（无小数） | `123` |
| ≥ 1,000 且 < 1,000,000 | 保留 2 位小数 + K | `12.34K` |
| ≥ 1,000,000 且 < 1,000,000,000 | 保留 2 位小数 + M | `12.34M` |
| ≥ 1,000,000,000 且 < 1,000,000,000,000 | 保留 2 位小数 + B | `12.34B` |
| ≥ 1,000,000,000,000 且 < 1,000,000,000,000,000 | 保留 2 位小数 + T | `12.34T` |
| ≥ 1,000,000,000,000,000 | 保留 2 位小数 + P | `12.34P` |

- **小数规则**：超过指定位数时四舍五入
- **有效数字**：仅 <1 的数值使用 2 位有效数字
- **数据源**：使用 sector 资源的 respawn 值，而非 yield/level

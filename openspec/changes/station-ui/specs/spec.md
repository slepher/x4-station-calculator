# Station Dashboard Specification

## Purpose
描述空间站建设仪表盘（StationDashboard）的交互逻辑与功能需求，旨在提供一个与资源流仪表盘风格一致的建设信息展示界面。

## ADDED Requirements

### Requirement: 视图模式切换
系统 SHALL 提供一个视图模式切换器，允许用户在不同的统计维度间切换。
- **材料视图**: 显示建设所需的物料清单与费用（当前默认且唯一可用视图）。
- **时间视图**: 预留入口，当前状态为禁用。
- **工人视图**: 预留入口，当前状态为禁用。

#### Scenario: 切换到材料视图
- **前提** 用户打开空间站计划页面
- **当** 用户查看建设仪表盘时
- **那么** 默认应选中“材料视图”
- **并且** 界面应显示建设费用分组和物料清单

### Requirement: 多分组布局结构
仪表盘 MUST 采用垂直排列的多分组结构，每个分组均支持折叠与展开。
- **总计分组**: 标题显示“总建设费用”，数值显示总金额（Cr）。展开后显示全局物料汇总。
- **模块分组**: 为每种（或每个）已添加的模块创建一个分组。标题显示“数量 x 模块名”，数值显示该项的总金额。展开后显示该项所需的物料详情。

#### Scenario: 展开模块分组
- **前提** 仪表盘显示了多个模块分组
- **当** 用户点击某个模块分组的标题时
- **那么** 该分组应展开并显示其内部的物料需求行
- **并且** 每行物料应包含数量、名称和对应的费用

### Requirement: 物料行视觉风格
物料展示行 SHALL 采用与资源流条目（StationWareFlow）一致的紧凑样式，但移除交互按钮。
- 必须包含状态点（颜色表示正负，建设费用默认为负或中性）。
- 必须包含物料名称和数值（数量及 Cr）。
- 不应包含收藏（Favorite）或锁定（Lock）按钮列。

## REMOVED Requirements

### Requirement: 旧版建设列表组件
现有的 StationConstruction 组件 MUST 被废弃并从系统中移除。

#### Scenario: 移除旧组件
- **前提** StationDashboard 已正确集成
- **当** 开发流程进入清理阶段
- **那么** 应删除 StationConstruction.vue 文件
- **并且** 移除所有对该组件的引用

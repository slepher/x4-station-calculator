# 需求说明：ship-build-material

## 目标
在“船只建造”页面的“建造材料”面板中，基于已选飞船与已选装备实时计算建造耗材与总价，并提供可展开的总览/分项明细展示。
面板风格对标 `StationDashboard`，明细复用 `CollapsibleDetailList`。
同时提供独立的材料价格滑条，并新增 method 下拉用于切换材料计算方法。

## 已确认方案（审核重点）
1. **method 下拉选择**
   - 在材料面板提供 method 下拉框。
   - 下拉选项为“飞船 `production.method` + 装备 `cost.method`”的去重聚合集合。
   - method 键名以游戏数据真实键为准（例如 `closedloop`、`terran`、`default`）。
2. **method 回退规则**
   - 计算任一飞船/装备成本时，若当前选中 method 不存在，则回退到 `default`。
   - 回退规则对飞船与装备统一生效。
3. **材料聚合结构**
   - 先展示“总材料 xxxCr（可展开）”，展开后显示按材料汇总行（`N x 材料A: xxxCr`）。
   - 再展示各装备明细，按“装备 ID 聚合”显示（`装备A x N xxxCr（可展开）`）。
   - 各装备展开后显示该装备组内材料明细（`N x 材料A: xxxCr`）。
4. **数据构成**
   - 总材料由“飞船基础建造成本 + 已选装备成本”共同组成。
   - 装备成本按当前配装选择统计数量后参与计算。
5. **样式与组件复用**
   - 面板视觉风格对标 `StationDashboard`。
   - 交互复用 `CollapsibleDetailList`（总览与分项均可折叠）。
6. **价格控制**
   - 面板底部增加独立材料价格拖动条。
   - 拖动条仅影响 CR 金额估值，不改变材料数量。
7. **文案与 i18n**
   - 本功能新增独立 i18n 键（不复用 station 板块文案键）。
8. **测试基线来源**
   - 标准测试状态与样本路径沿用 `ship-build-equipment` 文档约定。

## 边界
### In Scope
- 右侧“建造材料”面板从占位改为真实材料分析展示。
- method 下拉选择与 fallback 计算规则。
- 总材料与装备分项明细的折叠展示。
- 底部独立材料价格拖动条。
- 对应 i18n 文案与测试文档更新。

### Out of Scope
- 新增远程数据源或后端接口。
- 新增配装策略推荐与自动选装逻辑。
- 修改 ship-build-equipment 既有标准状态定义内容。

## 验收标准（DoD）
1. 选择飞船后，材料面板可显示“总材料”汇总行，并可展开查看按材料汇总明细。
2. 在存在配装选择时，面板可按“装备 ID 聚合”显示每项装备耗材与金额，并可展开查看分项材料。
3. method 下拉选项包含当前飞船/装备可见的所有 method 去重集合。
4. 当所选 method 不适用于某飞船或装备时，该条目自动回退到 `default` 并参与总价计算。
5. 材料价格拖动条变化时，CR 金额实时变化，材料数量保持不变。
6. 面板交互样式与 `StationDashboard` 风格一致，折叠行为复用 `CollapsibleDetailList`。
7. 文案使用独立 i18n 键，支持中英文。
8. 测试任务可基于 `ship-build-equipment` 的标准状态路径稳定执行。

## Bug Regression Tests (E2E)

### 17. Bug 4: Auto 节点转正

**场景**: 拖拽产品到已有 Auto 节点的规划区

**步骤**:
1. 创建一个规划区
2. 拖拽产品 A（如船体部件）到规划区，创建 Manual 节点
3. 删除产品 A 的 Manual 节点（降级为 Auto）
4. 再次拖拽产品 A 到同一规划区
5. **预期**: Auto 节点转正为 Manual，不创建新节点

**验证点**:
- [ ] 17.1 规划区只有一个产品 A 节点
- [ ] 17.2 节点状态为 Manual
- [ ] 17.3 上游节点正确扩展

### 18. Bug 5: 不同血统产品共存

**场景**: 拖拽不同血统的同种产品到规划区

**步骤**:

**验证点**:
- [ ] 18.1 规划区有两个船体部件节点

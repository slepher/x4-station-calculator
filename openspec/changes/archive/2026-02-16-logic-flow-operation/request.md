# Logic Flow 操作规范

## 一、拖拽状态变化

### 1.1 停靠区状态分类

| 状态 | 触发条件 | UI 表现 | 投放行为 |
|------|----------|---------|----------|
| **Normal** | 组内无该产物 | 蓝色边框 | 正常添加 |
| **Duplicated** | 组内已存在 Manual 节点 | 红色边框 + `Duplicate` 标签 | 禁止投放 |
| **Auto** | 组内存在 Auto 节点（虚线） | 绿色 `Auto` → 蓝色 `Manual` | 转正节点 |
| **Isolate** | 组内存在隔离节点（`node.isIsolated`） | 琥珀色 `Isolate` → 蓝色 `Connect` | 连接并扩展 |
| **Group Locked (匹配)** | 组被血统锁定，但产物匹配 | 琥珀色边框 | 正常添加（强制血统映射） |
| **Group Locked (拒绝)** | 组被血统锁定，产物不匹配 | 红色边框 + `🚫 Rejected` | 禁止投放 |

### 1.2 状态变化流程

#### 场景 A：拖拽到普通组（无锁定）

```
悬停组标题 → [Normal] 蓝色边框
     ↓
进入网格 → 显示停靠点（Phantom Node）
     ↓
投放 → 正常添加节点 + 自动扩展上游
```

#### 场景 B：拖拽到有 Auto 节点的组

```
悬停组标题 → [Auto] 绿色标签 "Auto"
     ↓
进入网格 → [Manual] 蓝色标签 "Manual" + 停靠点在 Auto 节点位置
     ↓
投放 → 节点转正（source: manual，实线边框）
```

#### 场景 C：拖拽到有隔离节点的组

```
悬停组标题 → [Isolate] 琥珀色标签 "Isolate"
     ↓
进入网格 → [Connect] 蓝色标签 "Connect" + 停靠点在隔离节点位置
     ↓
投放 → 节点解除隔离（isIsolated: false）+ 触发上游扩展
```

#### 场景 D：拖拽到血统锁定的组

```
悬停组标题 → 检查血统匹配
     ↓
┌────────────────┴────────────────┐
↓                                  ↓
[匹配] 琥珀色边框              [不匹配] 红色边框 + 🚫 Rejected
     ↓                                  ↓
进入网格 → 停靠点显示              禁止投放
     ↓
投放 → 强制血统映射后添加
```

#### 场景 E：拖拽到有重复 Manual 节点的组

```
悬停组标题 → [Duplicated] 红色边框 + "Duplicate" 标签
     ↓
禁止投放，无停靠点
```

### 1.3 状态优先级（从高到低）

```
1. Group Locked + 血统不匹配 → Rejected（最高优先，直接拒绝）
2. Duplicated（Manual 节点已存在）→ 禁止投放
3. Isolate（节点被隔离）→ 可连接投放
4. Auto → 可转正投放
5. Group Locked + 血统匹配 → 可正常投放
6. Normal → 正常投放
```

### 1.4 标签文字对照

| 状态 | Header 标签 | Grid 标签 | i18n key |
|------|-------------|-----------|----------|
| Auto | `Auto` | `Manual` | `logicFlow.auto` / `logicFlow.manual` |
| Isolate | `Isolate` | `Connect` | `logicFlow.isolate` / `logicFlow.connect` |
| Duplicated | `Duplicate` | - | `logicFlow.duplicate` |
| Rejected | `🚫 Rejected` | - | `logicFlow.rejected` |

## 二、候选区操作规范

### 2.1 产物卡片状态

| 产物类型 | 拖拽 | 快速添加按钮 (+) | T0 资源预览 |
|----------|------|------------------|-------------|
| T0 资源（矿石、硅、气体等） | ❌ 禁止 | ❌ 隐藏 | ❌ 不显示 |
| 能量电池 (Energy Cells) | ❌ 禁止 | ❌ 隐藏 | ❌ 不显示 |
| T1+ 产物 | ✅ 允许 | ✅ 显示 | ✅ 显示 |

### 2.2 已规划状态指示

- **绿点显示条件**：产物存在于任意组的 **非隔离节点** 中
- **隔离节点不计入**：`node.isIsolated === true` 的节点不触发绿点

### 2.3 快速添加菜单状态

| 菜单项状态 | 触发条件 | UI 表现 |
|------------|----------|---------|
| **Normal** | 组内无该产物 | 正常可点击 |
| **Duplicated** | 组内已存在 Manual 节点 | 灰化 + `Duplicate` 标签 |
| **Isolate** | 组内存在隔离节点 | 灰化 + `Isolate` 标签 |
| **Auto** | 组内存在 Auto 节点 | 正常可点击 + `Auto` 标签 |
| **Rejected** | 组被血统锁定且产物不匹配 | 灰化 + `🚫` 标识 |
| **Group Locked** | 组被血统锁定且产物匹配 | 正常可点击 + 显示血统名称 |

### 2.4 菜单交互行为

- 点击 "+" 按钮打开菜单
- 选择 "New Production Line" 后菜单自动关闭
- 选择现有组后菜单自动关闭

## 三、规划区节点操作规范

### 3.1 核心概念：产品 vs 模块

| 概念 | 定义 | 示例 |
|------|------|------|
| **产品 (Ware)** | 抽象的资源类型 | 矿石、硅、能量电池 |
| **模块 (Module)** | 具体的生产设施（带种族/血统） | 地球人矿石精炼厂、阿尔贡硅矿 |

**隔离操作的本质**：
```
点击 ✂️（隔离）→ 节点身份：模块 → 产品
                    "我生产这个" → "我从外部获取这个"
                    
点击 🔗（连接）→ 节点身份：产品 → 模块  
                    "我从外部获取" → "我生产这个"
```

**关键点**：
- 隔离后，节点不再是"生产模块"，而是"产品占位符"
- 隔离节点不计入"已规划"状态（因为它不生产）
- 隔离节点不参与上游扩展（因为它是外部供应）

### 3.2 节点类型定义

| 类型 | 定义 | 边框样式 | 属性 |
|------|------|----------|------|
| **Manual** | 用户手动拖入或转正 | 实线 | `source: 'manual'`, `isIsolated: false` |
| **Auto** | 系统自动生成 | 虚线 | `source: 'auto'`, `isIsolated: false` |
| **Isolated** | 被隔离的节点（产品占位符） | 实线 + 特殊标识 | `isIsolated: true` |

### 3.3 节点权限矩阵

| 节点状态 | 删除按钮 (🗑️) | 隔离按钮 (✂️/🔗) | 转正按钮 (➕) |
|----------|---------------|------------------|---------------|
| **纯 Manual**（无下游依赖） | ✅ 显示 | ❌ 隐藏 | ❌ 隐藏 |
| **纯 Auto**（系统生成） | ❌ 隐藏 | ✅ 显示（✂️） | ✅ 显示 |
| **混合型**（Manual + 被依赖） | ✅ 显示（降级为 Auto） | ✅ 显示（✂️） | ❌ 隐藏 |
| **Isolated**（隔离状态） | ❌ 隐藏 | ✅ 显示（🔗） | ❌ 隐藏 |
| **T0 资源节点** | ❌ 隐藏 | ❌ 隐藏 | ❌ 隐藏 |

### 3.4 按钮功能说明

#### 删除按钮 (🗑️)

| 节点类型 | 点击行为 |
|----------|----------|
| 纯 Manual | 删除节点 + 级联删除孤儿上游模块 + 级联删除孤儿上游隔离产品 |
| 混合型 | 降级为 Auto 节点（保留以满足下游依赖） |

**级联删除规则**：
1. 删除节点后，遍历其上游依赖
2. 若上游节点不被组内任何其他节点依赖 → 删除该上游节点
3. 若上游存在隔离状态的产品节点，且失去下游依赖 → 一并删除

#### 隔离按钮 (✂️/🔗)

| 当前状态 | 按钮图标 | 点击行为 |
|----------|----------|----------|
| 未隔离 | ✂️ (剪刀) | 切断上游依赖，节点身份从"模块"变为"产品占位符" |
| 已隔离 | 🔗 (链接) | 恢复上游依赖，节点身份从"产品占位符"变为"模块"，触发自动扩展 |

**隔离前提**：只有被组内其他节点消耗（存在下游消费者）的节点才显示隔离按钮。

#### 转正按钮 (➕)

- 仅显示在 Auto 节点上
- 点击后 `source` 从 `'auto'` 变为 `'manual'`
- 边框从虚线变为实线
- **T0 资源节点禁止转正**

### 3.5 按钮布局顺序

```
[左侧] ✂️/🔗 (隔离/连接)  ...  节点内容  ...  ➕ (转正) [右侧]
```

## 四、T0 资源特殊规则

### 4.1 T0 资源定义

- Tier 0 的基础资源：矿石 (Ore)、硅 (Silicon)、气体 (Gas) 等
- 能量电池 (Energy Cells) 作为特殊 T0 资源处理

### 4.2 T0 资源行为限制

| 操作 | T0 资源（除能量电池） | 能量电池 |
|------|----------------------|----------|
| 拖拽 | ❌ 禁止 | ❌ 禁止 |
| 快速添加按钮 | ❌ 隐藏 | ❌ 隐藏 |
| T0 资源预览 | ❌ 不显示 | ❌ 不显示 |
| 转正按钮 | ❌ 隐藏 | ❌ 隐藏 |
| 隔离按钮 | ❌ 隐藏 | ❌ 隐藏 |
| 删除按钮 | ❌ 隐藏 | ❌ 隐藏 |

### 4.3 T0 资源生命周期

- T0 资源节点由下游需求自动生成
- 当下游需求消失时自动清理
- 用户无法手动删除或隔离

### 4.4 T0 资源合并规则

- T0 资源无血统属性
- 规划组内所有来源的 T0 需求始终合并为同一个资源节点
- 不保存血统信息

## 五、规划组锁定（血统锁定）

### 5.1 锁定机制

| 属性 | 说明 |
|------|------|
| `group.isLocked` | 组是否被血统锁定 |
| `group.lockedLineage` | 锁定的血统名称（如 `terran`, `argon`） |

### 5.2 锁定状态行为

| 状态 | 拖入行为 | 血统处理 |
|------|----------|----------|
| **未锁定** | 正常接受 | 保留原始血统 |
| **锁定 + 匹配** | 正常接受 | 强制映射为锁定血统 |
| **锁定 + 不匹配** | 拒绝（🚫） | - |

### 5.3 锁定切换条件

- 仅当组内所有 **Manual 节点** 的血统一致时，允许切换锁定状态
- 血统不一致时，滑块置灰禁用

## 六、拖拽显示规范

### 6.1 显示内容：模块名称优先

在拖拽相关场景中，系统 SHALL 优先显示模块名称而非产品名称。

### 6.2 适用场景

| 场景 | 显示内容 | 说明 |
|------|----------|------|
| **紧凑版 - 现有组节点** | 模块名称 | 已有节点使用 `node.moduleId` 查找 |
| **紧凑版 - 预览节点** | 模块名称 | 根据 `wareId` + 血统查找对应模块 |
| **紧凑版 - 新产线 Header** | 模块名称 | 显示即将创建的模块名称 |
| **拖拽幽灵元素** | 模块名称 | 拖拽时跟随鼠标的元素 |

### 6.3 回退规则

| 节点类型 | 显示内容 | 原因 |
|----------|----------|------|
| T0 资源节点 | 产品名称 | T0 资源无对应模块 |
| 找不到模块 | 产品名称 | 兜底回退 |

> **注**：隔离节点在紧凑版中不显示（被 `nodesWithPreview` 过滤），因此无需回退规则。

### 6.4 血统选择逻辑

- **现有组**：使用组的 `lockedLineage`（锁定时）或 `subCategory`
- **新产线**：使用当前选中的 `activeSubCategory`
- **拖拽幽灵**：使用拖拽开始时的 `activeSubCategory`

## 七、术语对照表

### 7.1 节点隔离 vs 规划组锁定

| 概念 | 属性 | 状态标签 | 操作动词 | 语义 |
|------|------|----------|----------|------|
| **节点隔离** | `node.isIsolated` | `Isolate` / `Connect` | 隔离 / 连接 | 节点身份在"模块"与"产品占位符"之间切换 |
| **规划组锁定** | `group.isLocked` | `Locked` | 锁定 / 解锁 | 强制组内所有节点使用指定血统 |

### 7.2 i18n 键值汇总

| Key | 中文 | 英文 |
|-----|------|------|
| `logicFlow.auto` | 自动 | Auto |
| `logicFlow.manual` | 手动 | Manual |
| `logicFlow.isolate` | 隔离 | Isolate |
| `logicFlow.connect` | 连接 | Connect |
| `logicFlow.duplicate` | 重复 | Duplicate |
| `logicFlow.rejected` | 拒绝 | Rejected |
| `logicFlow.locked` | 已锁定 | Locked |
| `logicFlow.unlock` | 解锁 | Unlock |

## 八、属性重命名清单

以下属性需要从 `isLocked` 重命名为 `isIsolated`，以彻底区分"节点隔离"与"规划组锁定"：

### 8.1 节点属性
```typescript
interface FlowNode {
  // ...
  isIsolated: boolean  // 原 isLocked
}
```

### 8.2 Store 方法
| 原方法名 | 新方法名 |
|----------|----------|
| `toggleNodeLock()` | `toggleNodeIsolate()` |
| `convertToLockedAuto()` | `convertToIsolatedAuto()` |
| `unlockAndExpand()` | `connectAndExpand()` |

### 8.3 状态判断
```typescript
// 原：node.isLocked
// 新：node.isIsolated

// 已规划状态判断
isWarePlanned(wareId) {
  return groups.some(g => g.nodes.some(n => 
    n.wareId === wareId && !n.isIsolated  // 隔离节点不计入
  ))
}
```

## 九、隔离节点扩展规则

### 9.1 隔离节点不被自动打破

- **规则**: 上游扩展时遇到隔离节点应停止追踪，不自动打破隔离状态
- **场景**: 拖拽需要 hullparts 的产品时，若 hullparts 已隔离，则不自动连接

### 9.2 用户主动连接

- **触发**: 用户拖拽已隔离的产品到规划区
- **行为**: 
  1. 解除隔离状态 (`isIsolated = false`)
  2. 更新 `moduleId` 为正确的模块
  3. 扩展上游依赖

### 9.3 T0 预览追踪规则

- **规则**: T0 预览遇到隔离节点时停止追踪该分支
- **场景**: hullparts 隔离后，拖拽 weaponcomponents 时不预览 ore/silicon

## 十、紧凑模式 T0 显示规则

### 10.1 T0 显示位置

| 位置 | 是否显示 T0 |
|------|-------------|
| 组标题旁边 | ✅ 显示 |
| 模块区域 | ❌ 不显示 |

### 10.2 数据源一致性

- 紧凑模式和非紧凑模式使用同一数据源
- 区别仅在于显示方式和过滤条件

## 十一、其他功能需求

### 11.1 语言切换

- **需求**: 切换语言后，所有 ware 文本自动更新为新语言
- **实现**: 语言切换时调用 `prepareLocalizedWares()`

### 11.2 候选区锁定开关

- **需求**: 候选区的锁定开关状态传递给新建的规划区
- **实现**: `isDefaultLocked` 状态存储在 store 中

### 11.3 拖拽取消检测

- **需求**: 从候选区拖拽产品进规划区然后拖出来，产品不被添加
- **实现**: 使用 `isDragging` 状态检查拖拽是否有效

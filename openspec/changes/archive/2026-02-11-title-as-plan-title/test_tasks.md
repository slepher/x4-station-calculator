# 测试任务

- [x] **测试 1：默认标题行为**
  - 验证创建新方案时，标题显示为“空间站规划器”（或本地化的默认值）。
  - 验证内部 store 值为字符串空值。

- [x] **测试 2：标题编辑**
  - 点击编辑图标（或可点击的标题）。
  - 验证出现输入框，且显示当前标题。
  - 将标题更改为“我的新空间站”。
  - 按回车键或点击确认。
  - 验证标题显示更新为“我的新空间站”。
  - 验证浏览器页面标题更新。

- [x] **测试 3：空标题回退**
  - 编辑标题。
  - 清空输入框（使其为空）。
  - 确认编辑。
  - 验证标题回退到上一个有效标题（例如“我的新空间站”或“空间站规划器”）。

- [x] **测试 4：保存验证（无模块）**
  - 确保方案中**没有**模块。
  - 点击“保存”或“另存为”。
  - 验证出现 StatusMonitor 警告（例如“无法保存空方案”）。
  - 验证保存对话框**没有**打开。

- [x] **测试 5：带标题保存**
  - 向方案添加一个模块。
  - 将标题设置为“已保存的空间站”。
  - 点击“保存”。
  - 验证保存对话框使用“已保存的空间站”作为默认文件名。

- [x] **测试 6：新建方案重置标题**
  - 编辑当前标题为“旧方案”。
  - 点击“新建”按钮（如果有变更需先处理）。
  - 确认新建操作。
  - 验证标题重置为“空间站规划器”（默认值）。
  - 验证输入框在再次点击编辑时，初始值为“空间站规划器”（或空，取决于实现）。

- [x] **测试 7：编辑交互细节与撤回**
  - **前提**：当前标题为默认值（如“空间站规划器”）。
  - **操作**：点击标题进入编辑模式。
  - **验证**：输入框初始值应为“空间站规划器”，且文本被全选。
  - **验证**：输入框右侧出现“确认（打勾）”按钮。
  - **操作**：输入“新标题”，然后点击输入框外部（失焦）。
  - **验证**：编辑模式结束，标题显示为“空间站规划器”（原值），即操作被撤回。
  - **操作**：再次进入编辑模式，输入“最终标题”，点击“确认”按钮。
  - **验证**：编辑模式结束，标题更新为“最终标题”。

- [x] **测试 8：视觉稳定性（人工验证）**
  - **操作**：反复点击标题进入/退出编辑模式。
  - **验证**：工具栏高度无跳变。
  - **验证**：文字大小无明显跳变（除了字重或输入框样式的细微差别）。

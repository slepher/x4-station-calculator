## Web Integration Tests

- [ ] W1: 标签拖拽重排成功
  - **目标**: 使用 Playwright Mouse API 验证标签顺序变化
  - **步骤**:
    1. 打开页面，等待页面加载完成（`#debug-ready-marker` 出现）。
    2. 点击顶部标签栏右侧 `+`（`.add-btn`）三次，创建 3 个空间站标签。
    3. 点击第 1 个空间站标签，在名称输入框中输入 `Alpha`，按 `Tab` 确认。
    4. 点击第 2 个空间站标签，在名称输入框中输入 `Beta`，按 `Tab` 确认。
    5. 点击第 3 个空间站标签，在名称输入框中输入 `Gamma`，按 `Tab` 确认。
    6. 确认当前从左到右顺序为 `Alpha -> Beta -> Gamma`（不包含“帝国总览”标签）。
    7. 将 `Gamma` 标签拖拽到 `Alpha` 标签前方并释放。
    8. 若拖拽后顺序未变化，最多再重试 2 次同样拖拽动作。
    9. 断言最终顺序为 `Gamma -> Alpha -> Beta`。
    10. 断言“帝国总览”标签仍在最左侧首位。

- [x] W2: 帝国总览固定首位
  - **目标**: 验证拖拽后 `.overview-tab` 始终位于首位

    3. 检查右下角 `StatusMonitor` 状态提示，确认出现 `save` 分类且消息内容为“保存/Save”语义。

    7. 断言刷新后的分站顺序仍为 `Gamma -> Alpha -> Beta`。
    8. 断言“帝国总览”标签仍在最左侧首位，且分站标签数量仍为 3。

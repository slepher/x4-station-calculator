# sector-link 需求说明

## 目标
在帝国视图中提供两类能力：
- 星区管理与连接管理 UI：支持星区排序、空间站分配/回收、星区连接创建与删除。
- （已迁移）星区物流纯函数能力迁移至 `sector-link-calc` change 统一维护。

## 已确认需求

### 1. 星区管理面板（SectorManagementPanel）
- 顶部“星区管理”区域为单行布局：左标题、中输入框、右 `+`。
- 新建星区输入框创建后不清空。
- 新建星区重名自动追加序号，从 `2` 开始（例：`Trade Hub`, `Trade Hub 2`）。
- 未分配区标题为“未分配”。
- 未分配区同样提供单行“标题 + 输入框 + `+`”创建空间站。
- 未分配区新建空间站：
  - 创建后不自动跳转到空间站页面。
  - 输入框不清空。
  - 重名自动追加序号，从 `2` 开始（例：`Alpha`, `Alpha 2`）。
- 未分配区空间站显示删除按钮：
  - 无模块（`modules` 无有效计数）直接删除。
  - 有模块时弹确认框，确认后删除。
- 星区内空间站 chip 显示与连接区一致风格的 `x` 按钮，点击后移回未分配。
- 星区“空间站区 / 连接区”标题与内容同一行。
- 空态高度对齐：空间站区与连接区使用一致最小高度。
- 图标风格统一：拖拽把手与连接把手采用一致线性图标风格。

### 2. 拖拽态显示规则
- 拖拽空间站时，隐藏星区内“连接区”。
- 拖拽星区连接时，隐藏星区内“空间站区”。
- 拖拽星区排序时，同时隐藏星区内“空间站区”和“连接区”。

### 3. 星区连接反馈
- 成功创建连接时不显示“连接已创建”提示。
- 连接失败（自连接、重复、无效目标）及删除连接成功提示保留。

### 4. Station Tab 行为
- 空星区在 tab 上不显示星区项，也不显示对应分割线。

### 5. Empire 空判定
- `isEmptyForSave` 仅在“同时没有空间站且没有星区”时返回空。

### 6. 变更边界说明
- `sector-link` 仅承载星区管理/连接管理 UI 与交互规则。
- 纯函数计算流量（含分网、分层分配、连接级流向输出）已迁移至 `sector-link-calc`。

## 边界

### In Scope
- 星区管理面板内的星区/空间站/连接交互与文案。
- Station Tab 空星区隐藏逻辑。
- Empire 空判定逻辑。

### Out of Scope
- 价格驱动或时间切片仿真。
- 多货物共享运力/仓储联合优化。
- 跨实体（站点-站点、站点-星区）统一网络优化。
- 纯函数物流分配与结果结构（迁移到 `sector-link-calc`）。

## 验收标准（DoD）
- 星区与未分配两处创建输入均支持重名自动编号且不清空输入。
- 未分配区删除空间站符合“无模块直删/有模块确认”规则。
- 星区内空间站可一键移回未分配。
- 三类拖拽态显示规则符合预期。
- 空星区不在 tab 中显示（含分割线）。
- Empire 空判定按“空间站与星区同时为空”生效。

## 未决项
无。

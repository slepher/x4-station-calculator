# x4-map-resource 需求说明

## 目标
为 map 页面增加资源筛选工作台，支持按资源组合、日光和最低丰度快速筛选星区，并提供按条件排序的命中候选列表。
该能力需要与现有左上角 sector 搜索共存，避免高亮和选中语义冲突。
同时将地图右侧入口改为按钮式展开面板，并让关闭行为只清理地图高亮而不重置当前面板配置。

## 已确认方案（审核重点）

### 1. 入口与整体布局
- 默认状态下，map 页面右上角显示“资源 + 过滤图标”的按钮，作为资源筛选入口。
- 入口按钮与左上角搜索框共同占据地图顶部工具区；按钮图标使用人类日常可理解的过滤漏斗形状。
- 入口按钮需要与搜索框处于相同的地图覆盖层级，并固定在地图内容区右上角，而不是作为 `map-layout` 的独立并列列块参与外层布局。
- 入口按钮点击后，页面直接切换为左右并列布局：
  - 左侧为地图，自适应剩余空间
  - 右侧为固定宽度资源栏，宽度保持与内嵌态一致
- 不存在“点击按钮后先在地图右上角展示资源过滤浮层”的中间状态。
- 资源栏自上而下包含三块：
  - 资源多选 tag 区
  - 已选资源配置区
  - 命中候选框
- 工作态右侧资源栏提供关闭按钮，点击后关闭资源工作态并退出左右并列布局。
- 关闭后页面回到默认状态，只保留右上角“资源 + 漏斗图标”按钮，不再显示地图右上角资源区。
- 关闭资源过滤面板时，不清空已选筛选项、最低丰度、日光输入和面板内部配置。
- 关闭资源过滤面板时，需要清理地图上的资源筛选高亮数据；重新打开面板后恢复到关闭前的内容设置。
- 上述配置保留仅限当前页面会话，不要求刷新页面后继续保留。

### 2. 资源选择与配置
- 资源列表参考 `regionyields.json`，覆盖 `ore / silicon / methane / hydrogen / helium / ice / rawscrap / nividium`。
- tag 固定顺序为：金属矿石、硅、甲烷、氢、氦、冰、废料、N矿。
- UI 文案中 `rawscrap` 显示为 `Scrap`，内部仍映射到 `rawscrap`。
- 额外增加特殊 tag：`日光`，排在最后，颜色需明显区别于普通资源。
- 右上角资源 tag 采用短 i18n 显示：
  - 普通资源统一使用 `res.*` 字典短名。
  - `sunlight` tag 不显示 `日光`，而是显示 `res.energycells` 对应短名。
- tag 支持多选，筛选语义为 `AND`。
- 每个已选资源都可以独立设置最低丰度。
- 新选中资源时，默认最低丰度为 `lowest`。
- `日光` 选中后使用输入框设置最低日光百分比，默认值为 `100%`。
- 当已选普通资源数量大于等于 `2` 时，配置区顶部额外显示 `所有项` 控件。
- 调整 `所有项` 下拉时，需要同步更新当前全部已选资源的最低丰度。
- 未选中 tag 使用透明背景，仅保留资源色边框；选中后使用资源色填充。
- 下方配置区继续使用原有长 i18n：
  - 普通资源配置行显示游戏资源全称。
  - 日光配置行继续显示 `日光 / Sunlight` 文案。

### 3. 丰度来源与判定规则
- 丰度等级顺序以 `regionyields.json` 中每个资源自身的 `yields[].name` 顺序为准。
- 星区实际资源命中与排序数据以 `maps.json` 中 sector 的 `resources[]` 为准。
- 资源是否满足门槛，按 sector 对应资源的 `yield` 与已选资源最低丰度比较判定。
- 某 sector 若缺少任一已选资源，则该 sector 不命中。
- `日光` 的筛选值来自 `maps.json` 中 sector `area.sunlight`，并按 `1.0 = 100%` 映射到输入框百分比。
- 普通资源下拉中的可选上限按“当前过滤可达”计算：保留其它已选条件、忽略当前资源自身门槛，再求该资源当前上下文中的最高可达 yield。
- 高于当前过滤可达上限的下拉项需要禁用，但不自动改写用户当前值。

### 4. 命中候选框
- 资源配置区下方显示命中候选框。
- 进入右侧过滤区后，无论当前是否已选中资源，都显示命中候选框。
- 候选列表只显示同时满足全部已选资源、日光输入和最低丰度的 sector。
- 当当前没有选中任何 tag，候选列表展示默认前 `10` 条 sector。
- 默认前 `10` 条 sector 按 `ore + silicon + methane + hydrogen + helium` 的 `level` 总和从高到低排序。
- 当存在普通资源筛选时，候选按“已选资源在该 sector 中的 `level` 总和”从高到低排序。
- 当仅选中日光筛选时，候选按 sector 日光百分比从高到低排序。
- 最多显示 `10` 个候选。
- 点击候选后的行为与左上搜索框命中结果点击一致：聚焦并选中对应 sector。

### 6. 关闭按钮与 tag 布局
- 右侧过滤区在未选择任何 tag 时也会显示关闭按钮。
- 关闭按钮不能遮挡上方资源 tag 区。
- 不允许仅在“已选择资源”时为关闭按钮预留空间，而在“未选择资源”时出现覆盖。
- 关闭按钮与 tag 区应通过统一头部布局或统一留白策略避免重叠。

### 5. 搜索与资源筛选并存策略
- 采用方案 A：搜索与资源筛选为独立双通道。
- 左上搜索结果不被资源筛选强制裁剪。
- 右上命中候选框只反映资源筛选结果。
- 地图渲染时区分三类状态：
  - 当前选中 sector
  - 搜索命中高亮
  - 资源筛选命中高亮
- 高亮优先级为：当前选中 > 搜索命中 > 资源命中。
- 当某 sector 同时命中搜索与资源筛选时，主样式以搜索高亮为准，并允许叠加较弱的资源提示。
- 当存在资源或日光筛选时，六边形内部不再使用种族染色：
  - 命中项使用第一个已选筛选项的颜色填充
  - 未命中项内部改为透明

## 边界

### In Scope
- map 页面资源筛选入口按钮、工作态侧栏与关闭行为。
- 资源 tag 多选与已选资源独立最低丰度下拉。
- 日光特殊筛选项与百分比输入。
- 已选普通资源大于等于 `2` 个时的 `所有项` 批量设置控件。
- 资源命中候选框、排序规则与点击聚焦行为。
- 空选择状态下的默认前 `10` 条候选排序。
- 当前过滤可达约束与不可达选项禁用。
- 搜索高亮与资源高亮的分层共存规则。
- 资源工作态下的地图内部染色切换。
- 当前页面会话内的面板配置保留，以及关闭面板时资源高亮清理。
- 关闭按钮与 tag 区的不遮挡布局。

### Out of Scope
- 修改左上搜索框的匹配规则与候选排序逻辑。
- 为资源筛选结果增加分页、收藏或刷新后持久化方案。
- 引入新的地图数据源或重写 sector 布局算法。
- 改造整个 map 页视觉主题。

## 验收标准（DoD）
- 默认状态下，资源筛选以“资源 + 漏斗过滤图标”按钮作为地图右上角入口显示，并与左上搜索框同处顶部工具区。
- 点击入口按钮后，页面直接切换为“左侧地图 + 右侧固定宽度资源栏”的两列布局。
- 关闭资源栏后，页面回到默认单地图状态，只显示右上角入口按钮。
- 资源 tag 支持多选，语义为 `AND`。
- 每个已选资源都能单独设置最低丰度，默认值为 `lowest`。
- `日光` tag 排在最后，选中后显示输入框，默认值为 `100%`，并按 `json 1.0 = 100%` 参与过滤。
- 右上角资源 tag 对普通资源显示 `res.*` 短名，对 `sunlight` 显示 `res.energycells` 短名；下方配置区继续显示原有长 i18n。
- 当已选普通资源数量大于等于 `2` 时，出现 `所有项` 下拉，并能同步修改全部已选资源的最低丰度。
- 普通资源下拉会禁用高于当前过滤可达上限的选项，但不会自动改写当前值。
- 只有同时满足全部已选资源、日光和最低丰度的 sector 才会进入命中候选。
- 命中候选在普通资源场景下按资源 `level` 总和降序排序，在纯日光场景下按日光百分比降序排序，最多显示 `10` 个。
- 点击命中候选后，地图聚焦并选中对应 sector，行为与搜索结果点击一致。
- 在右侧过滤区内未选中任何 tag 时，候选列表仍会显示，且默认按 `ore + silicon + methane + hydrogen + helium` 的 `level` 总和降序取前 `10` 条。
- 搜索与资源筛选可同时存在，左上搜索结果不被资源筛选强制裁剪。
- 地图高亮优先级明确：当前选中 > 搜索命中 > 资源命中。
- 资源工作态下，仅命中项保留内部填充色，未命中项内部透明。
- 关闭资源过滤面板后，地图资源高亮会被清理，但面板内已选资源、最低丰度和日光输入保持不变。
- 在同一页面会话内重新打开资源过滤面板时，界面恢复到关闭前的配置内容。
- 右侧过滤区在未选择任何 tag 时，关闭按钮也不会遮挡资源 tag。

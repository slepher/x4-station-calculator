# resource-pie 需求说明

## 目标
为 map 页面资源过滤增加“多资源饼图染色”能力。
当用户同时选中多个普通资源时，地图不再按第一个资源整块染色，而是按该 sector 当前资源现状渲染饼图切片，让用户在地图上直接看到各资源占比。

## 已确认方案（审核重点）

### 1. 染色触发条件
- 当资源过滤未激活时，地图继续保持现有非资源过滤染色逻辑。
- 当资源过滤激活且只存在一个参与染色的项目时，地图继续允许使用单色填充。
- 当资源过滤激活且存在多个参与染色的普通资源时，命中 sector 改为饼图染色，不再使用“第一个资源整块填充”的旧逻辑。
- 未命中的 sector 继续保持资源过滤态下的透明内部填充，不参与饼图渲染。

### 2. 参与染色的资源范围
- 普通资源的参与范围以当前已选资源 tag 为准。
- 参与染色的顺序必须遵循资源 tag 区中的固定排列顺序，而不是按 sector 实际资源大小重新排序。
- `日光` 不是普通资源切片的一部分。
- 当 sector 同时存在任一普通资源参与染色时，`日光` 不参与该 sector 的染色。
- 只有在当前染色集合中没有普通资源参与时，`日光` 才可以作为单独的染色来源继续工作。

### 3. 饼图份额计算
- 多资源饼图切片大小按 sector 中各资源的 `level` 计算。
- 每个参与染色的资源必须保留最小显示份额 `5%`。
- 在满足每个资源至少 `5%` 的前提下，其余份额再按各自 `level` 比例分配。
- 当所有参与资源的 `level` 总和为 `0`，仍然按最小显示份额规则为各资源保留可见切片，并在剩余空间中按稳定规则均分。
- 份额计算结果总和必须稳定收敛到 `100%`，避免出现可见缝隙或溢出覆盖。

### 4. 扇区渲染表现
- 饼图切片绘制区域仍然受 sector 六边形边界约束，不得超出六边形。
- 单 sector cluster 与多 sector cluster 都要保持一致的饼图渲染语义。
- 切片颜色继续复用资源 tag 对应颜色，保证面板与地图颜色语义一致。
- 搜索高亮、当前选中态与资源命中态的优先级保持既有规则：`当前选中 > 搜索命中 > 资源命中`。
- 饼图渲染只改变资源命中态下的内部填充方式，不改变边框、文字和 glow 优先级规则。

### 5. 数据流与兼容策略
- 资源面板不能再只向地图输出一个 `primary color`，而是要输出可描述多资源切片的数据。
- 地图工作台负责转发“命中 sector 列表 + 每个 sector 的切片描述”给 SVG 画布。
- 旧的单色资源染色行为需要兼容：
  - 单资源时可继续输出单色填充
  - 多资源时输出饼图切片
- 该变更不要求修改候选排序、最低丰度判定、tag 选择逻辑或 tooltip 内容。

## 边界

### In Scope
- map 页面资源过滤命中 sector 的多资源饼图染色。
- 按资源 tag 固定顺序输出切片顺序。
- 按 `level` 计算切片大小，并为每个参与资源保留至少 `5%` 份额。
- `日光` 在存在其它资源时不参与染色，仅在无普通资源参与时作为单独染色来源。
- 资源面板到地图工作台再到 SVG 画布的染色数据结构升级。

### Out of Scope
- 修改资源过滤候选列表排序规则。
- 修改最低丰度过滤规则或 tag 选择交互。
- 调整 tooltip 资源列表内容与顺序。
- 引入新的地图布局算法或重做 sector 边框/label 视觉风格。

## 验收标准（DoD）
- 当只选中一个普通资源时，命中 sector 继续按单色资源填充显示。
- 当同时选中多个普通资源时，命中 sector 显示为多切片饼图，不再整块使用第一个资源颜色。
- 多资源切片顺序与资源 tag 固定顺序一致。
- 多资源切片大小以 sector 对应资源的 `level` 为基础，并且每个参与资源至少可见 `5%`。
- 当选中资源中包含 `日光` 且同时存在普通资源时，sector 染色中不出现日光切片。
- 当只有 `日光` 可参与染色时，地图仍可继续使用日光单独染色。
- 搜索高亮与当前选中态的优先级不因饼图染色而退化。
- 未命中的 sector 在资源过滤态下仍保持透明内部填充。

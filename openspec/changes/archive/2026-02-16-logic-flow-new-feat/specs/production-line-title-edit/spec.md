# Production Line Title Edit Specification

## Purpose
描述产线组标题编辑功能的交互逻辑与数据持久化需求，确保用户能够自定义产线组名称，且 UI 交互与 Toolbar 标题编辑保持一致。

## Requirements

### Requirement: 产线组标题编辑交互 (Title Editing Interaction)
系统 SHALL 允许用户在规划区产线组标题上直接编辑名称。

#### Scenario: 进入编辑模式
- **前提**: 用户查看产线组标题
- **当** 用户点击标题区域
- **那么** 标题 SHALL 变为输入框，且自动获得焦点
- **并且** 输入框右侧 SHALL 显示一个确认（打勾）按钮
- **并且** 输入框初始值 SHALL 为当前标题

#### Scenario: 确认编辑
- **前提**: 用户正在编辑标题
- **当** 用户按下回车键 OR 点击确认按钮
- **那么** 标题更改 SHALL 被保存
- **并且** 输入框关闭，显示新标题

#### Scenario: 取消编辑（失焦）
- **前提**: 用户正在编辑标题
- **当** 输入框失去焦点（且未点击确认按钮）
- **那么** 编辑操作 SHALL 被取消
- **并且** 标题回退到编辑前的值

#### Scenario: 空值回退
- **前提**: 用户正在编辑标题
- **当** 用户将输入框清空并确认
- **那么** 标题 SHALL 回退到上一个有效值
- **并且** 不允许保存空标题

### Requirement: 自定义标题持久化 (Custom Title Persistence)
系统 SHALL 持久化用户自定义的产线组标题。

#### Scenario: 保存自定义标题
- **前提**: 用户编辑产线组标题为"我的产线"
- **当** 用户确认编辑
- **那么** `customName` 字段 SHALL 被设置为"我的产线"
- **并且** 后续显示 SHALL 使用该自定义值

#### Scenario: 自定义标题优先显示
- **前提**: 产线组存在 `customName` 字段
- **当** 渲染产线组标题时
- **那么** 系统 SHALL 显示 `customName` 而非自动计算的名称

#### Scenario: 自定义标题不自动更新
- **前提**: 用户已自定义产线组标题为"我的产线"
- **当** 用户添加更高 Tier 的产物
- **那么** 标题 SHALL 保持为"我的产线"
- **并且** 不会自动更新为新产物的名称

### Requirement: 视觉一致性 (Visual Consistency)
产线组标题编辑 UI SHALL 与 Toolbar 标题编辑保持视觉一致。

#### Scenario: 编辑样式一致
- **前提**: 用户进入标题编辑模式
- **当** 观察输入框样式
- **那么** 输入框 SHALL 使用与 Toolbar 相同的样式类
- **并且** 确认按钮 SHALL 使用相同的图标和颜色

#### Scenario: 高度稳定性
- **前提**: 用户切换编辑模式
- **当** 观察产线组 Header 区域
- **那么** 区域高度 SHALL 保持稳定，无跳变

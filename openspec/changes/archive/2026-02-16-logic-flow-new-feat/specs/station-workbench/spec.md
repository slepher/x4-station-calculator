# Station Workbench Specification

## ADDED Requirements

### Requirement: 主视图切换 (Main View Switching)
系统 SHALL 提供一个视图模式切换器，允许用户在不同的统计维度间切换。列表内容和底部控制栏随视图动态变化。视图切换按钮 SHALL 位于语言选择器左边，紧贴语言选择区。

#### Scenario: 切换到逻辑组网视图
- **前提** 用户当前处于量化生产视图
- **当** 用户点击"逻辑组网"按钮
- **那么** 内容区域 SHALL 切换为逻辑组网布局（候选区 + 规划区）
- **并且** 按钮 SHALL 显示紫色高亮激活状态

#### Scenario: 切换到量化生产视图
- **前提** 用户当前处于逻辑组网视图
- **当** 用户点击"量化生产"按钮
- **那么** 内容区域 SHALL 切换为三栏网格布局
- **并且** 按钮 SHALL 显示蓝色高亮激活状态

#### Scenario: 视图切换按钮位置
- **前提** 用户查看工具栏
- **当** 观察视图切换按钮位置
- **那么** 按钮 SHALL 位于工具栏最左侧
- **并且** 按钮组采用圆角胶囊式设计

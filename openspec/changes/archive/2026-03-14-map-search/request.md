# map-search 需求说明

## 目标
为 map 页面增加 sector 搜索能力，让用户可以通过输入框快速定位地图中的 sector。
搜索结果需要提供与空间站界面一致的基础交互模式：输入框、下拉候选、点击候选。

## 已确认方案（审核重点）

### 1. 搜索入口与布局
- map 页面左上角新增 sector 搜索框。
- 搜索框与左下角 `Scale` 面板形成左右对称布局。
- 搜索候选列表从输入框下方向下弹出，不采用向右弹出。
- 只要求交互模式与空间站界面一致，不要求视觉样式完全复刻。

### 2. 搜索对象与匹配字段
- 搜索对象仅为 `sector`。
- 支持按 `name` 搜索。
- 支持按当前语言下的 `localeName` 搜索。
- 当当前 locale 为 `en` 时，只按 `name` 搜索，不额外单独搜索 `localeName`。
- 不搜索 `cluster`、`station`、`zone` 等其它对象。

### 3. id 搜索规则
- `id` 匹配只在输入满足 `cluster + 完整数字` 形式时启用。
- 示例：`cluster 01` 可以命中 `cluster_01`，但不能命中 `cluster_011`。
- `id` 匹配必须是完整数字匹配，不能用前缀数字误命中更长编号。
- 不支持仅输入 `sector` 或 `sector + 数字` 作为 `id` 命中条件。
- 因此 `sector` 相关输入只参与 `name / localeName` 搜索，不参与 `id` 搜索。

### 4. 搜索结果联动
- 输入时实时过滤 sector 并展示下拉候选。
- 当命中结果数量小于 `10` 个时，地图上高亮全部命中的 sector。
- 当命中结果数量大于等于 `10` 个时，不进行地图批量高亮，只展示下拉候选。
- 点击下拉候选后，地图聚焦到对应 sector，并保持该 sector 的明确选中/高亮状态。
- 候选项主显示遵循当前语言：
  - `en` 下主显示 `name`
  - 非 `en` 下主显示 `localeName`
- 候选项附加信息按命中类型显示：
  - `id` 命中时显示 `sectorId`
  - 非 `en` 且 `name` 命中时显示原始 `name`
  - 英文环境 `name` 命中、以及 `localeName` 命中时不显示附加文本
- 当候选列表中存在 `id` 命中项时，下拉列表宽度需要增大，以保证主显示名称尽量完整。

### 5. 聚焦与缩放行为
- 点击候选时，如果当前 `scale < 100%`，先将地图缩放提升到 `100%`。
- 如果当前 `scale >= 100%`，保持当前缩放值不变。
- 完成缩放后，将视口 focus 到目标 sector，默认按“尽量居中”处理。
- 输入命中多个结果但未点击候选时，不自动 focus 第一个结果。
- 点击候选后，不修改搜索框当前输入内容。
- 点击候选后，搜索框失焦并关闭下拉列表。

### 6. 清空搜索行为
- 清空搜索时，清除搜索高亮。
- 清空搜索时，清除当前搜索选中态。
- 清空搜索时，不重置当前地图缩放与平移位置。

## 边界

### In Scope
- map 页面 sector 搜索框与下拉候选交互。
- `name / localeName / 受限 id` 搜索匹配规则。
- 命中数小于 `10` 时的地图高亮。
- 点击候选后的缩放校正与聚焦。
- 清空搜索后的状态回收。

### Out of Scope
- 搜索 cluster、station、zone 或其它地图实体。
- 修改地图数据源结构。
- 重新设计 map 页面整体视觉风格。
- 模糊纠错、拼音、跨语言同时搜索等扩展能力。

## 验收标准（DoD）
- map 页面左上角存在 sector 搜索框，候选列表向下弹出。
- 输入 `name` 可返回对应 sector 候选。
- 非 `en` locale 下，输入当前语言 `localeName` 可返回对应 sector 候选。
- `en` locale 下只按 `name` 搜索，不额外进行 `localeName` 搜索分支。
- 输入 `cluster 01` 这类完整数字格式时，可命中对应 cluster id；且 `cluster 01` 不能误命中 `cluster_011`。
- 输入 `sector` 或 `sector + 数字` 时，不作为 id 匹配条件。
- 搜索结果数小于 `10` 时，地图高亮全部命中 sector。
- 搜索结果数大于等于 `10` 时，地图不进行批量高亮。
- 点击候选时，若当前缩放小于 `100%`，地图会先调整到 `100%`，随后聚焦到目标 sector。
- `en` locale 下，候选项主显示 `name`。
- `id` 命中时，候选项额外显示 `sectorId`，并增大候选列表宽度以尽量完整显示主名称。
- 非 `en` 且 `name` 命中时，候选项额外显示原始 `name`；英文环境 `name` 命中不额外显示重复文本。
- 点击候选时，不改写搜索框已有输入内容，并且搜索框失焦。
- 清空搜索时，高亮与搜索选中态被清除，当前缩放与平移保持不变。

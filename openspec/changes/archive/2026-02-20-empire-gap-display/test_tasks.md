## Web Integration Tests

### 测试前置知识

**分组产生条件**：
- **帝国运营**：来自产品 + 运营，满足 `netRate < 0` 或 `priority > 0` 的项。
- **帝国补给**：来自补给组，满足 `netRate < 0`，或 `netRate > 0` 且在当前站 `plannedModules` 中存在对应模块。

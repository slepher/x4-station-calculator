# 需求说明：blueprint-preset

## 目标

在飞船配装页面提供“预设配装 + 蓝图配装”的统一加载入口，并确保蓝图状态名称、`isDirty`、红点提示在所有关键路径下行为一致、可预测。

## 背景

现有蓝图能力已支持预设与用户蓝图，但在“已保存蓝图 -> 再载入预设”路径上，状态归属与脏状态表达不一致，导致用户感知为“切换了蓝图对象”或“显示为空配”。

## 已确认方案（审核重点）

1. 蓝图列表分组与命名
- 在 Fit 标题栏右侧按钮弹层中分组展示：
  - `预设配装`：内置预设（空配/低配/中配/高配）
  - `蓝图配装`：用户保存蓝图

2. 入口与弹层约束
- 入口位于 Fit 标题栏右侧。
- 加载弹层最大高度固定为 `400px`。

3. 状态显示总规则
- 当前蓝图有名称：状态显示蓝图名。
- 当前蓝图无名称且来自预设且未发生实质变化：状态显示预设名。
- 当前蓝图无名称且发生实质变化：状态显示“自定义”。

4. “已保存蓝图后载入预设”规则（核心）
- 前置：当前存在“活动已保存蓝图”（有 `id`、有 `activeBlueprintId`、同 ship）。
- 执行“载入预设”时：不切换活动蓝图对象，保留当前蓝图 `id/name`。
- 点击“保存”时：保存到当前蓝图（覆盖当前蓝图），不是新建。
- 状态文案保持为当前蓝图名。

5. 脏状态与红点规则（含 C/U 槽）
- `isDirty` 必须由“是否有实质性变化”决定，而非仅由操作动作决定。
- 比较范围包含连接装备与存储配置（含 C 槽、U 槽）。
- 实质变化：
  - `isDirty = true`
  - 显示红点
- 无实质变化：
  - `isDirty = false`
  - 不显示红点

## 场景验收表

| 场景 | 状态显示 | isDirty | 红点 |
|------|----------|---------|------|
| 载入预设（普通路径） | 预设名 | true | 不显示 |
| 预设后修改装备 | 自定义 | true | 显示 |
| 载入已保存蓝图 | 蓝图名 | false | 不显示 |
| 已保存蓝图后修改 | 蓝图名 | true | 显示 |
| 删除当前蓝图 | 自定义 | true | 显示 |
| 保存蓝图 | 蓝图名 | false | 不显示 |
| 已保存蓝图后载入预设且有实质变化 | 蓝图名 | true | 显示 |
| 已保存蓝图后载入预设但无实质变化 | 蓝图名 | false | 不显示 |

## In Scope

- Fit 标题栏右侧蓝图入口的分组、命名、弹层高度。
- 预设加载与活动蓝图归属规则。
- 蓝图状态名、`isDirty`、红点联动规则统一。

## Out of Scope

- Ship Build 三栏布局重构（Fit/Picker/Equipment/Status 布局）。
- 设备筛选器与分页器交互改造（除与蓝图状态直接相关部分）。
- 非蓝图相关的材料价格配色与滑条逻辑。

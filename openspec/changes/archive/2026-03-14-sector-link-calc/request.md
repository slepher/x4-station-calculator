# sector-link-calc 需求说明

## 目标
在不引入时间切片仿真的前提下，将“空间站缺口展示”与“星区中转站存储/运输需求”接入星区物流纯函数结果。
本次重点是统一计算口径：本地空间站贡献与外星区中转贡献在同一口径下合并结算。

## 已确认方案（审核重点）

### 1. 计算边界与基础口径
- 计算按静态 `netRate`（每小时）进行，不做时间切片。
- 物流连接距离默认 `1`。
- 资源范围仅 `container`，不纳入 `solid/liquid`。
- 允许为目标修改纯函数输入/输出接口，以提高业务映射效率。

### 2. 空间站缺口开关改造（子网口径）
- 现有“显示缺口”规则继续沿用当前代码的产物显示/隐藏规则。
- 现有“全帝国总缺口”范围改为：
  - 基准星区：当前空间站所属星区。
  - 计算域：该星区所在 `SectorNetworkComponent` 子网。
- 明细结构按“产物归并”展示，且 A/B 结果合并到同一产物列表：
  - A：本星区内每个空间站条目（产出/需求贡献）。
  - B：同子网其他星区条目（按星区聚合后的产出/需求贡献）。
- 示例：同一产物可同时出现 `站A产出10`、`站B产出20`、`星区C需求10`、`星区D需求40` 四条。
- 未分配星区（`sectorId=null`）时，缺口开关行为无效。

### 3. 星区中转站面板改造（存储/运输）
- 现状：仅基于本星区内空间站需求计算存储/运输。
- 目标：额外叠加“外星区中转贡献”，并使用同一套计算口径。
- 路径口径采用“本星区与连接星区的一跳边”：
  - 起点为本星区：计为输出。
  - 终点为本星区：计为输入。
- 明细中新增“外星区条目”，名目使用外星区名称。
- 中转增量与本地空间站贡献一起进入同一存储/运输公式（统一口径）。
- 中转侧暂不处理供给不足修正。

### 4. 统一公式口径
- 存储需求沿用现有口径，缓冲小时固定 `12h`：
  - `productionStorageVolume = productionRate * unitVolume * 12`
  - `consumptionStorageVolume = consumptionRate * unitVolume * 12`
  - `totalRequiredStorageVolume = max(productionStorageVolume, consumptionStorageVolume)`
- 运输需求沿用现有口径：
  - `transportVolume = abs(netRate) * unitVolume`
- 本地空间站贡献与外星区中转贡献在公式输入层合并。

### 5. 后续增补需求（本次同步）
- 纯函数输入过滤口径：
  - 输入阶段按“类别口径（`||` 右侧条件）”筛选产物；
  - 展示汇总阶段保持“`netRate + 类别口径`”。
- 纯函数执行时机：
  - 不再随中转页 tab 切换重复计算；
  - 改为载入后计算，并在空间站产物流变化时重算。
- 空星区中转可视：
  - 中转 tab 的隐藏条件由“本星区无站”改为“本星区无站且未连接到有站星区”。
  - 对无本地站但有连接站点的星区，纯函数允许产物集需有回退来源（来自连接且有站星区）。
- 结果正确性与可观测性：
  - 修复链路流量 key 解析（`linkId` 含 `|` 时不得破坏 `from/to`）。
  - 增加按星区粒度的纯函数日志，输出输入净值、边流、缺口、分配结果。
- 中转视图展示规则：
  - 仓储/运输视图中，外星区条目显示为“输入/输出”（输入绿、输出红）；
  - 本星区空间站条目继续显示“产出/消耗”。
  - 空数据时，仓储/运输分组标题与内容同显同隐（仅显示空态，不单独显示标题）。
- 建筑区空态文案：
  - 空建筑区不再显示“功能占位”语义，改为正式空态提示。
- Tab 栏可用性：
  - 当 tab 超出可视范围时，提供左右按钮横移 tab 栏。

## 边界

### In Scope
- 基于 `SectorNetworkComponent` 的空间站缺口展示范围重构。
- 缺口明细模型重构：本星区按站、外星区按星区，按产物归并合并展示。
- 中转站存储/运输面板接入外星区一跳边中转增量。
- 为上述能力调整纯函数接口与聚合中间结构。

### Out of Scope
- `solid/liquid` 物流纳入统一框架。
- 多跳路径逐段可视化与全路径解释 UI。
- 中转侧供给不足的回退与再分配机制。
- 本次新增 UI 控件（例如可调缓冲小时控件）。

## 验收标准（DoD）
- 缺口开关开启时，当前空间站仅显示其所属子网内数据，不再是全帝国范围。
- 同一产物明细中可同时出现“本星区空间站条目”和“其他星区条目”，并为叠加结果。
- 未分配星区空间站开启缺口开关时不产生子网缺口结果。
- 中转站存储/运输面板在原有本地数据基础上，新增外星区一跳边贡献条目（名目为外星区名）。
- 外星区贡献与本地贡献按统一公式计算并合并到最终存储/运输需求。
- 中转页切换 tab 不应触发纯函数重复计算。
- 无本地站但连接到有站星区时，中转 tab 与中转物流可见。
- 仓储/运输空态下不显示孤立分组标题。

## 未决项
无。

# 需求说明：船只配装装备选择器

## 目标
统一船只配装页面在候选数量为 `0/1/>1` 时的槽位交互，并将 `>1` 的选择流程改为可筛选、可分页、可确认的展开式选择器。

## 已确认方案（审核重点）

### 1. 槽位显示与点击逻辑
- **候选 = 0**：显示空槽。
- **候选 = 1**：槽位显示该唯一候选名称；第一次点击执行装备，再次点击执行取消装备（设为 `null`）。
- **候选 > 1**：槽位显示当前已选或空槽；点击后展开 picker，候选在右侧列表中选择并通过确认生效。

### 2. 展开态布局（三行）
- 第一行（高度 `25.6px`）：左侧 `标准/简化`，右侧 `确定/取消`。
- 第二行（高度 `25.6px`）：左侧槽位分页签（L1/L2...），右侧候选分页按钮。
- 第三行：左侧保持展开前的槽位与兼容性风格，`compatibility-box` 内原内容替换为 `filter-block`；槽位列表与该区域同属第三行左侧容器；右侧为候选列表。
- `picker-title` 移除。
- `确定/取消` 按钮样式与左侧模式按钮一致（圆角、同高），并保留 `mr-1`。

### 3. 过滤规则与来源
- **Race**：从当前展开槽位的实际候选集合动态计算（`equipment.race`）。
- **MK**：从当前展开槽位的实际候选集合动态计算（`equipment.mk`）。
- **Tag**：使用预置集合 `standard/advanced/xenon/mining/missile/highpower`，仅显示当前候选中实际出现的项，并走 i18n 翻译。
- 标签计数规则：任一组计数都基于“其余两组过滤后”的候选数量。

### 4. 展开态交互
- 展开后不锁死全局交互。
- 允许 `标准/简化` 切换。
- 允许 group/tab 切换，并保持展开；切换后按 `connectionKeys` 锚点重映射到对应槽位，同时刷新 filter 与候选。
- 点击左侧 `slot.type`（E/S/W/T/R）会直接关闭 picker。

### 5. 关闭后的模式回退
- 若 picker 关闭时当前为 `group` 且不满足 `canSwitchToGroupMode`，自动回退到 `connection`。
- 关闭状态下若存在类型冲突，禁止再次切到 `group`。

### 6. 确认与蓝图更新
- 确认时对 `pickerTarget.connectionKeys` 全量赋值。
- 赋值后沿用 store 的空 group 清理：`equipment_id` 与 `shield.equipment_id` 同时为空时移除该 group。

## 边界

### In Scope
- 槽位 `0/1/>1` 三类显示与交互重构。
- 展开态三行布局与按钮样式统一。
- 过滤/分页/候选选择/确认流程。
- 展开态下的模式与分组切换行为。
- 关闭后的模式回退与冲突约束。

### Out of Scope
- 装备对比能力。
- 额外的候选推荐算法。

## 验收标准（DoD）
1. 候选=1 时显示唯一候选，点击可装备，再次点击可取消装备。
2. 候选>1 时点击槽位展开 picker，候选不在槽位内平铺展示。
3. 展开态为三行布局，前两行高度固定 `25.6px`。
4. 第三行左侧保持原有槽位/兼容性视觉风格，仅将 `compatibility-box` 内内容替换为 `filter-block`。
5. Race/MK 来源于实际候选；Tag 使用预置集合并 i18n。
6. 标签仅显示候选中存在的值，计数遵循“其余两组过滤后计数”。
7. 允许展开态下切换 `标准/简化` 与 group/tab；切换后保持展开并重映射槽位。
8. 展开态点击 `slot.type` 时关闭 picker。
9. picker 关闭后若不满足 group 切换条件，自动回退 `connection`。
10. 点击确认后更新目标连接并触发空 group 清理。

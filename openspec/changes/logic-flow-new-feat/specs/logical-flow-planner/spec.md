# Logical Flow Planner Specification

## MODIFIED Requirements

### Requirement: 产线组管理 (Production Line Group Management)
系统 SHALL 允许用户将生产链组织为独立的"产线组"。
- **容器化**: 每个产线组是一个独立的布局容器，内部遵循 4 列布局。
- **自动命名**: 系统 SHALL 为新创建的产线组自动生成名称，格式为 `[一级分类] - [二级分类] - [组内 Tier 最高的第一个产物名]`。
- **自定义标题**: 用户 SHALL 能够通过点击标题区域编辑自定义名称。编辑后标题固定，不再自动更新。
- **排序**: 用户 SHALL 能够通过拖拽调整同一 Tier 列内产物节点的上下显示顺序。

#### Scenario: 自动命名产线组
- **前提**: 画布为空
- **当** 用户从"工业 - Terran"候选区拖入"计算机基板"到新建区
- **那么** 系统创建一个新产线组，默认名称为"工业 - Terran - 计算机基板"

#### Scenario: 自定义标题后保持不变
- **前提**: 用户已将产线组标题编辑为"我的产线"
- **当** 用户添加更高 Tier 的产物
- **那么** 标题 SHALL 保持为"我的产线"
- **并且** 不会自动更新为新产物的名称

## ADDED Requirements

### Requirement: 节点悬停高亮链路 (Node Hover Highlight Chain)
系统 SHALL 在用户悬停节点时，高亮显示其完整的上下游依赖链路。

#### Scenario: 悬停触发高亮
- **前提**: 规划区包含多个产线组和节点
- **当** 用户悬停某节点
- **那么** 系统 SHALL 计算该节点的上下游依赖链路
- **并且** 相关节点、产线组容器和连线 SHALL 显示高亮样式

#### Scenario: 离开节点清除高亮
- **前提**: 用户正在悬停某节点
- **当** 鼠标离开节点
- **那么** 所有高亮样式 SHALL 被移除

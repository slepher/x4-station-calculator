## Unit Tests

### 产线组标题编辑

- [x] **测试 1：标题编辑交互**
  - 点击产线组标题区域
  - 验证输入框出现并获得焦点
  - 验证确认按钮显示在输入框右侧

- [x] **测试 2：标题确认编辑**

- [x] **测试 3：标题取消编辑**

- [x] **测试 4：空值回退**

  - 确认编辑
  - 验证标题回退到上一个有效值

- [x] **测试 5：自定义标题不自动更新**
  - 设置自定义标题为"我的产线"
  - 添加更高 Tier 的产物

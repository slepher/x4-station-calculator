# Station Sidebar Navigation Specification

## Purpose

完善两种产能侧栏的窄栏导航、分组编辑与浏览状态恢复；蓝图保留创建入口，实况绑定管理沿用条目菜单。

## MODIFIED Requirements

### Requirement: Sidebar layout

Sidebar SHALL 固定最顶部展开／收起按钮及蓝图最底部“＋”；两者之间的功能入口、地形改造树、置顶、搜索、分组和站点 SHALL 共用一个滚动区域，使用剩余空间。MUST 不使用上下分区、横向分割线或 `55%` 等分区高度上限。实况不显示底部“＋”。蓝图保持平铺站点，实况按已有星区组展示。展开显示名称，收起保留可操作图标；组折叠与侧栏收起互相独立。业务分组颜色、折叠按钮和成员竖线保留。所有展示结构 MUST 由 presenter 组装。

当前项 SHALL 通过背景与文字高亮辨认，MUST 不使用左侧半月形或 inset 竖条高亮；包含当前项且未选中的分组使用轻背景提示，分组成员颜色竖线保留。

#### Scenario: 统一滚动且两端按钮固定

- **前提** sidebar 内容超过可用高度。
- **当** 用户在展开、收起或窄屏抽屉中滚动 sidebar 内容。
- **那么** 功能入口、特殊树、置顶、搜索、分组和站点在同一容器内滚动，顶部展开／收起按钮保持原位。
- **并且** 蓝图“＋”始终位于 sidebar 最底部，实况没有底部“＋”；不出现上下分割线或独立的功能区滚动条。

#### Scenario: 收起后继续导航

- **前提** 用户已选中一个站点，所属组已展开。
- **当** 用户收起侧栏。
- **那么** 当前工作区和站点保持不变，固定入口、组标识和该站图标仍可点击。
- **并且** 点击其他站点图标后，主区域与高亮同步切换。

#### Scenario: 独立折叠当前组

- **当** 用户点击当前站点所属组的折叠箭头。
- **那么** 仅隐藏该组成员，其他组和主区域不变。
- **并且** 组标识仍提示其包含当前项；点击名称导航到原 Transit，点击“⋮”只打开编辑浮层。

#### Scenario: 窄栏分组提示

- **当** 用户收起 sidebar。
- **那么** 顶部按钮、分组折叠箭头和条目图标沿同一固定中心线排列，展开／收起不改变主图标左边距或行高，拖拽手柄不挤动图标；分组使用彩色圆角箭头，展开向上、收起向下。
- **并且** 展开成员旁显示同色竖线；地形改造树同样提供独立折叠控制，折叠不切换当前工作区。

### Requirement: Blueprint station reorder

Blueprint Sidebar SHALL 沿用站点领域顺序，排序请求必须为当前全部站点 ID 的完整排列，由 `useEmpireDataStore.reorderStationsInEmpire()` 最终写入。Live SHALL 仅支持同组成员和分组的侧栏展示排序，不修改业务归属、领域组顺序或分组算法结果。搜索和收起状态 SHALL 禁止拖动排序；跨组投放 MUST 被拒绝。

#### Scenario: 蓝图排序保存

- **当** 用户完成蓝图站点排序并按原流程保存蓝图。
- **那么** 站点顺序按新排列持久化，成员内容和当前站点 ID 不变。

#### Scenario: 实况同组排序与非法投放

- **当** 用户在展开且无搜索的实况侧栏中将站点在同组内重新排序。
- **那么** 只保存该绑定、该组的导航展示顺序。
- **并且** 将站点拖到其他组不改变源组、目标组、绑定和持久化顺序。

### Requirement: Station menu

Sidebar SHALL 按模式和条目身份输出合法操作，行内“⋮”与右键入口使用同一动作集合。蓝图提供原重命名、复制、确认删除；实况提供到已有绑定管理的入口，绑定调整／解除在原流程处理。已有可删除的未绑定规划条目仍按原权限确认删除。MUST 不用删除规划替代解除绑定，不修改存档实体。

#### Scenario: 蓝图与实况操作隔离

- **当** 用户分别打开蓝图站点和已绑定实况站点的操作菜单。
- **那么** 蓝图可执行规划编辑，实况可进入绑定管理。
- **并且** 实况菜单不把该绑定站点暴露为可直接删除的规划条目，菜单点击不触发站点导航。

## ADDED Requirements

### Requirement: Mode specific primary action

蓝图底部 SHALL 显示“添加空间站”，调用已有创建能力；实况 SHALL 不显示底部“＋”或“绑定空间站”主入口。实况条目菜单继续提供已有绑定管理。MUST 不新增侧栏创建分组入口。

#### Scenario: 创建蓝图站点

- **当** 用户点击蓝图底部添加入口。
- **那么** 在当前蓝图创建并选中规划站点，调用原保存流程。

#### Scenario: 实况不显示主入口

- **当** 用户使用实况 sidebar 的展开、收起或窄屏抽屉状态。
- **那么** 均不显示底部添加／绑定主按钮。
- **并且** 条目已有绑定管理菜单仍定位到所属组的原流程。

### Requirement: Group name and color editing

已有可编辑业务分组 SHALL 提供名称与预设色板浮层。名称经 trim 后不得为空；色板提供九种预设颜色和选中圈，已有自定义色可继续保留。应用 SHALL 原子更新同一组的名称和颜色草稿；取消／外部关闭 SHALL 不写入。名称与颜色 MUST 不作为身份键。颜色 SHALL 同步到标题、边线、窄栏组标识。

#### Scenario: 编辑后保存与放弃

- **当** 用户修改名称和颜色并应用。
- **那么** 产能侧栏及读取同一组的地图展示同步使用草稿值，并产生原有未保存状态。
- **并且** 只有原保存动作使其刷新后保留；执行放弃则恢复原名称和颜色。

#### Scenario: 非法编辑或对象变化

- **当** 输入为空白、分组已消失，或编辑期间切换绑定。
- **那么** 不提交修改；空白输入提示错误，失效上下文关闭浮层。
- **并且** 取消不会覆盖其他入口产生的更新。

### Requirement: Sidebar preferences and restoration

Sidebar SHALL 按生产模式持久化展开状态和宽度，按当前蓝图／绑定身份隔离折叠集合、滚动位置、置顶和实况导航顺序。搜索和浮层草稿 MUST 不持久化。普通视图往返恢复浏览位置；明确外部导航优先定位目标，其次才恢复位置。实体失效时 SHALL 清理其偏好。

#### Scenario: 恢复而不误展开

- **当** 用户手动折叠当前组、切换视图再返回，或列表发生无关刷新。
- **那么** 恢复已折叠状态和滚动位置，不因当前项仍属于该组自动展开。

#### Scenario: 外部导航与身份隔离

- **当** 用户从其他视图明确导航到一个有效站点。
- **那么** 展开目标组并滚动使其可见，包括目标与原选中站点相同的情形。
- **并且** 切换到另一蓝图／绑定不继承原上下文的折叠、置顶和顺序。

### Requirement: Search and identification

Sidebar SHALL 按站点／组名称过滤，站点命中保留父组，组名称命中显示该组成员。搜索期间临时展开命中组，清除搜索恢复此前折叠和滚动状态。SHALL 提供无结果提示、完整名称 tooltip、可辨认的当前项及所属组状态。

#### Scenario: 搜索与恢复

- **当** 用户搜索某站点后清除搜索。
- **那么** 搜索期间可见命中站点和父组，清除后恢复之前浏览状态。
- **并且** 搜索本身不切换业务选中项；搜索期间发生明确外部导航则结束搜索并定位目标。

### Requirement: Sidebar width and narrow screen drawer

展开侧栏 SHALL 支持有界宽度调整并记忆，收起再展开恢复原宽度。窄屏 SHALL 使用抽屉，不覆盖桌面宽度偏好。导航选择关闭抽屉；折叠组、编辑菜单和颜色不关闭抽屉。

#### Scenario: 调宽与窄屏切换

- **当** 用户调整侧栏宽度后收起、展开，再将窗口切换到窄屏。
- **那么** 桌面恢复已保存宽度，窄屏以抽屉覆盖内容。
- **并且** 返回桌面后仍恢复桌面宽度，调整中断不留下全局监听或拖动状态。

### Requirement: Pinned shortcuts and existing status indicators

Sidebar SHALL 支持常用站点置顶快捷入口，原组成员仍保留且共享业务身份。SHALL 仅展示已有业务提供的未保存、异常、重算等状态，收起时保留标记与解释提示。

#### Scenario: 置顶站点与删除清理

- **当** 用户置顶并通过快捷入口选择站点。
- **那么** 快捷入口与原条目指向同一站点，高亮一致，不改变其归属。
- **并且** 站点删除或不再属于当前上下文后，该快捷入口被清理。

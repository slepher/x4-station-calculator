# 请求：产能侧边栏交互完善

## 目标

借鉴用户提供的 Chrome 垂直标签栏截图，改善蓝图产能与实况产能侧边栏的阅读、定位和分组管理体验。延续项目已有业务模型，提供可导航的窄图标栏；蓝图保留添加空间站，实况不提供底部“＋”入口。

## 已确认方案（审核重点）

### 业务范围与入口

- 本变更只改进蓝图产能和实况产能侧栏；地图绑定面板仅作为既有流程的跳转目的地。
- 两种模式共享视觉与基础交互。蓝图底部入口为“添加空间站”，创建规划站点；实况不提供底部“＋”或“绑定空间站”按钮，绑定管理沿用条目菜单。
- 蓝图当前是平铺站点列表，继续使用已有结构；实况展示已有星区组及其站点。只有实际存在的业务分组才提供分组编辑，不为模仿 Chrome 给蓝图添加分组模型。
- 侧栏不承担新建分组职责，不提供新建分组按钮或菜单。已有自动分组工作台入口继续按原权限显示，进入原工作台处理分组。
- 蓝图条目复用重命名、复制、删除能力；实况条目进入绑定管理处理绑定、调整和解除。已有未绑定规划条目的删除仍遵守原权限，不能将删除规划、解除绑定和删除游戏存档实体混为一谈。

### P0：基本交互

- 展开时显示图标和名称；收起时保留可点击的窄图标栏，包括功能入口、分组标识、展开组的站点和蓝图底部业务入口。顶部按钮、分组箭头与导航图标使用同一中心线。
- 分组参照 Chrome 使用彩色圆角折叠按钮：展开显示向上箭头，收起显示向下箭头，展开成员旁显示同色竖线。地形改造树沿用同一提示方式，折叠不改变当前工作区。
- 组折叠与侧栏收起相互独立。每组可以独立折叠，允许多个组同时展开；折叠当前项所在组不改变主区域内容。
- 分组箭头只负责折叠；组名称／导航图标保持原来的 Transit 导航语义；“⋮”只打开分组编辑浮层。
- 分组编辑浮层包含名称输入框和预设色板，参照截图组织。空白名称不可提交；名称经去除首尾空白后应用。使用明确的应用／取消动作，取消和点击外部关闭不写入草稿。
- 色板使用灰、蓝、红、黄、绿、粉、紫、青、橙九种预设色，当前颜色有选中圈；已有自定义颜色保留并可识别，不要求用户先替换为预设色。
- 分组颜色用于标题、组边线和收起状态的组标识；当前条目高亮与悬停态可区分。折叠的组仍可识别其中存在当前选中项。
- 收起或名称截断时提供完整名称提示；站点提示包含已有的所属分组信息。
- 顶部展开／收起按钮固定，不随内容滚动；蓝图“＋”始终固定在最底部，实况不显示“＋”。中间的功能入口、地形改造树、置顶、搜索、分组和站点共用一个滚动区域，使用两端按钮之间的剩余空间。
- 不使用上下分区或横向分割线，不设置 `55%` 等分区高度上限；展开、收起和窄屏抽屉使用相同滚动边界。业务分组折叠、颜色和成员竖线保留。
- 展开／收起只改变文字和次要操作的可见性，主图标列与顶部按钮保持同一左边距和中心线，行高不变，切换时图标不横向或纵向跳动。拖拽手柄不挤动图标。
- 当前项使用背景和文字高亮，不绘制左侧半月形／内侧竖条高亮；含当前项的分组使用轻背景提示，业务分组的成员颜色竖线保留。
- 收起／重新展开和视图往返时恢复各自分组折叠状态、滚动位置和已有业务选中状态，不重置当前工作区。

### P1：定位与空间利用

- 展开状态允许拖动边缘调整宽度，设定上下限并记忆；收起后再次展开恢复该宽度。
- 外部导航到站点时展开所属组，并将条目滚动到可见范围；用户刚手动折叠当前组时，不因无关数据刷新立即重新展开。
- 搜索匹配站点或组名称，保留所属组上下文；命中组名称时展示该组成员。清除搜索恢复搜索前折叠和滚动状态，当前业务选中项保持不变。
- 悬停“⋮”与右键菜单提供相同的合法条目操作；点击操作按钮不触发条目选择。
- 实况条目绑定管理仍定位到条目所属组的原流程；不为底部入口增加新的地图跳转。

### P2：补充体验

- 保留蓝图已有站点排序；支持实况组内展示排序和分组展示排序，只改变导航顺序，不改变业务归属或分组算法结果。搜索期间禁止排序，收起时不提供拖动排序。
- 常用站点可置顶，在固定入口之后展示快捷入口；原组仍保留该站点。两个入口使用同一稳定身份和选中状态，置顶不改变业务归属。
- 使用已有未保存、绑定异常、需重算等业务状态显示少量提示标记，不增加新的告警计算规则；窄图标栏也能看到提示。
- 窄屏使用抽屉展开侧栏，关闭抽屉不修改桌面展开宽度和分组状态；点击导航项后关闭抽屉，编辑浮层操作不关闭抽屉。

### 保存与隔离

- 分组名称、颜色写入现有业务分组草稿，沿用现有保存／放弃语义；地图与产能视图读取同一份业务数据。应用浮层不自动保存整份绑定，以免顺带保存其他未提交编辑。
- 侧栏展开状态、宽度为按蓝图／实况区分的本地偏好；分组折叠、滚动、置顶和实况展示顺序再按当前蓝图或绑定身份隔离并持久化。
- 搜索词、编辑浮层草稿、拖动临时状态不持久化。实体移除后清理失效偏好；旧数据缺少新增字段时按明确默认值初始化。

## 边界

### In Scope

- 上述 P0、P1、P2 功能按优先级分段实施；P2 属于本变更后段任务。
- 两种产能模式的侧栏、对应 presenter、必要的领域操作与本地偏好、中文／英文文案。
- 严格使用 `store → presenter → vue`；界面分组、图标、状态和动作由 presenter 组装，Vue 不直接调用 store，不增加适配层或 view model 层。

### Out of Scope

- 跨组拖动、通过拖动改变绑定或业务归属、新建分组、通用浏览器标签页系统、关闭标签即删除站点。
- 新增快捷键和方向键导航体系；保留原生按钮与现有基本可访问性，不因裁剪功能主动破坏既有行为。
- 改造地图侧面板本身、修改自动分组算法、修改游戏存档空间站实体、增加蓝图分组业务。

## 验收标准（DoD）

1. 蓝图点击添加创建规划站点；实况在展开、收起和抽屉状态均不显示“＋”或绑定主入口，条目已有绑定管理菜单保持可用。
2. 收起后仍能切换功能和站点；收起、折叠组、调整宽度均不改变业务选中项。
3. 分组可独立折叠；名称／图标、箭头、“⋮”三个点击区互不误触。
4. 分组名称／颜色应用后各视图同步；空名称被拒绝，取消无变更，保存刷新保留、放弃恢复原值。
5. 顶部展开／收起按钮及蓝图底部“＋”始终可访问，滚动中间内容不移动这两个按钮；中间所有内容统一滚动，无上下分割线或百分比分区高度上限。名称提示、当前项／所属组高亮与业务分组提示保持可用。
6. 模式／蓝图／绑定切换及刷新后偏好正确隔离；恢复滚动与外部定位按设计的明确优先级执行。
7. 搜索保留组上下文；清除后恢复原浏览状态；排序不会丢失成员或改变归属，跨组投放被拒绝。
8. 置顶与原条目选择一致；失效置顶被清理；状态标记来自已有业务事实。
9. 窄屏抽屉正常开关和导航，桌面宽度不被覆盖；所有新文案支持中英文。
10. 每个行为变更任务附带 focused Unit 并执行通过，`npm run build` 通过；真实浏览器交互证据由后续 `/x4:e2e-test sidebar` 负责，Unit 不替代拖动与布局验证。

## 未决项

无。宽度、断点、色值等实现默认值在 design.md 中明确；不增加待定业务流程。

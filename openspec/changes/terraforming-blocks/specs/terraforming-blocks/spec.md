# terraforming-blocks Specification

## Purpose

将 terraforming 任务树与任务队列中的 stat 展示收敛为统一的方块语义：任务树中同一 stat 的条件与效果必须合并为同一条展示；任务队列中所有可方块化的 stat 变化必须改为单行效果方块图。

## ADDED Requirements

### Requirement: 同 Stat 条件与效果合并展示

**前提** 某个 terraforming 项目同时包含某 stat 的条件与 effect，且该 stat 存在 `ranges`

**当** 中列任务节点渲染 stat 信息

**那么** 同一 `statId` 的条件与效果必须合并为同一条 stat 行

**并且** 不得再分别在 `condition-list` 与 `effect-list` 中重复渲染该 stat

**并且** 该 stat 行必须同时包含：
- 完整 value 色带
- 当前值表达
- 条件命中区间外框（若存在条件）
- 效果变化叠加（若存在 effect）
- 效果文案（若存在 effect）

**并且** 完整 value 色带中的每个方块必须对应一个真实 value，而不是一个 state

### Requirement: 条件外框沿用现有方块语义

**前提** 某个 stat 行存在条件信息，且该 stat 存在 `ranges`

**当** 任务节点渲染该 stat 行

**那么** 条件命中区间必须继续使用覆盖在方块图上方的连续外框表达

**并且** 外框命中规则继续区分：
- `condition.min/max` → state 区间
- `condition.minvalue/maxvalue` → value 区间

**并且** 外框不得被移动到方块图旁边或独立成第二条需求条

**并且** 效果变化必须与条件外框共存在同一条方块图中

**并且** 命中区若覆盖多个连续 value，必须合并为连续外框

### Requirement: 三种场景共用同一句法

**前提** 任务节点渲染 stat 行

**当** 某 stat 仅存在条件

**那么** 显示 `stat名 + 方块图 + 条件外框`

**当** 某 stat 仅存在效果

**那么** 显示 `stat名 + 变化值 + 方块图 + 效果叠加`

**当** 某 stat 同时存在条件与效果

**那么** 显示 `stat名 + 变化值 + 方块图 + 条件外框 + 效果叠加`

**并且** 这三种场景必须复用同一条 stat 行布局，而不是切换为不同组件结构

**并且** 若存在变化值文案，则必须显示在方块图之前

**并且** `stat名`、变化值、方块图之间必须保留放大的固定横向间距

### Requirement: 已执行过的一次性项目不再显示方块预览目标

**前提** 某个一次性项目已经执行过，且某个 stat 存在 `ranges`

**当** 任务节点渲染该 stat 行

**那么** 不再显示该 stat 的效果预览目标

**并且** 仍保留当前值表达与条件外框（若存在条件）

**并且** 同一项目中的数字型 stat 仍保留执行结果文本

### Requirement: Increase 与 Decrease 的视觉语义

**前提** 某个 stat 行存在 effect 叠加，且该 stat 存在 `ranges`

**当** 渲染 `increase`

**那么** 必须使用空心目标格加内部 1/2 实心小方块表示

**并且** 内部 1/2 小方块的颜色必须与该格自身的 `rgb` 一致

**当** 渲染 `decrease`

**那么** 必须使用当前实心格内部打孔的语义表示

**并且** 孔洞边框颜色必须与该格自身的 `rgb` 一致

**并且** 孔洞填充色必须是背景色

**并且** 不得使用会透出底层方块颜色的半透明 rgba 作为孔洞填充

### Requirement: 无 Range Stat 使用单行文本

**前提** 某个 terraforming stat 没有 `ranges`

**当** 该 stat 出现在任务节点中

**那么** 不得渲染方块图

**并且** 若同时存在条件与效果，必须显示为单行文本

**并且** 文本格式至少包含当前值、变化结果和需求文本

**并且** 数字型 stat 不得拆分成上下两条“条件”和“效果”文本

### Requirement: 任务队列中的 Stat 变化方块化

**前提** 右列任务队列存在某条执行记录，且该记录的 before/after stat 可映射到 `ranges`

**当** 该记录渲染 stat 变化

**那么** 必须使用单行效果方块图展示该 stat 的变化

**并且** 该方块图必须基于执行前状态与本条记录带来的变化构建

**并且** 队列中的 stat 行不显示条件外框

**并且** 队列中的 stat 行不显示效果文案（如 `+2(max:5)` / `-2(min:3)`）

### Requirement: 任务队列中的数字型 Stat 保持单行数值变化

**前提** 右列任务队列中某条执行记录的 stat 没有 `ranges`

**当** 该记录渲染 stat 变化

**那么** 必须使用单行数值变化文本展示

**并且** 文本至少包含执行前值与执行后值

**并且** 不得为该类 stat 强行构造伪方块图

### Requirement: 非 Stat 条目不参与合并

**前提** 任务节点中存在项目依赖、rebate、sideEffect 或 description

**当** 中列任务节点渲染条件区与效果区

**那么** 仅“同一 stat 的条件与效果”参与单条合并

**并且** 项目前置依赖继续保留在条件区独立条目中

**并且** rebate、sideEffect、description 继续保留为独立效果条目

**并且** 不得为了追求统一而把非 stat 条目伪装成 stat 方块行

## Web Integration Tests

### 测试前置知识

**分组产生条件**：
- **帝国运营**：来自产品 + 运营，满足 `netRate < 0` 或 `priority > 0` 的项。
- **帝国补给**：来自补给组，**不再按 netRate 过滤**。

### 测试1：显示分组开关

#### 测试步骤

1. **添加空间站A**：电子黏土产线
   - 点击"添加空间站"
   - 搜索"电子黏土"
   - 点击"电子黏土产线"添加到规划区
   - 开启"工人运算"开关

2. **锁定量子管**（产生帝国运营）
   - 在资源流列表中找到量子管行
   - 点击锁定按钮锁定量子管

3. **添加空间站B**
   - 点击"添加空间站"
   - 切换到空间站B

4. **开启显示缺口**
   - 在空间站B中找到"显示缺口"开关（在"站内补给"旁边）
   - 点击开关切换为 ON

5. **验证分组显示**
   - 切换到资源视图
   - 验证顶部显示"帝国运营"分组（包含量子管）
   - 验证顶部显示"帝国补给"分组（包含食物配给、医疗物资）

#### 验收标准

- [x] "显示缺口"开关显示在"站内补给"旁边
- [x] 开关默认为 OFF 状态
- [x] 点击开关后状态切换为 ON
- [x] 开启后资源视图顶部显示分组
- [x] 帝国运营包含量子管
- [x] 帝国补给包含食物配给、医疗物资

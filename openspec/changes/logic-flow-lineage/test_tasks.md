# 集成测试任务：逻辑组网血统隔离与锁定 (Logic Flow Lineage & Locking)

## 1. 物理隔离与主键验证 [PASSED]

### 测试目标
验证 `moduleId` 作为主键能正确实现产线隔离，且 T0 资源能正确合并。

### 测试步骤
1. **新建工作区**，进入逻辑流视图。
2. **添加泰拉迪产线**: 从候选区切换到 `INDUSTRIAL_TELADI`，添加“船体部件”。
   - 验证：规划区出现“泰拉迪船体部件”节点，且其上游包含“泰拉迪石墨烯”。
3. **添加通用产线**: 从候选区切换到 `INDUSTRIAL_DEFAULT`，再次添加“船体部件”。
   - 验证：规划区出现第二个“通用船体部件”节点，与泰拉迪节点并存，互不干扰。
4. **验证 T0 合并**: 观察两者的上游“能量电池”。
   - 验证：整个规划组内只存在一个“能量电池”节点，且需求量为两者的总和。

## 2. 锁定机制验证 [PASSED]

### 测试目标
验证 iOS 风格滑块的锁定逻辑及准入拦截。

### 测试步骤
1. **候选区锁定**: 在候选区开启"锁定"滑块。
   - 验证：滑块状态为激活，旁显示当前血统名。
2. **拖入匹配模块**: 拖入一个与锁定血统一致的模块。
   - 验证：成功加入组。
3. **拖入不匹配模块**: 切换候选区分类，尝试拖入一个不属于该体系的模块。
   - 验证：拖拽过程中鼠标指针显示 🚫 标识，释放后模块未被加入组。
4. **切换权限检查**: 
   - 手动添加两个不同血统的模块到同一个组.
   - 验证：该组 Header 上的锁定滑块应处于禁用状态。
5. **锁定血统强制约束 (Bug 9 回归)**:
   - 创建规划区，拖入 Teladi 滋养油。
   - 锁定该产线的 lineage。
   - 切换候选区到 Split，拖入 Split 的医疗物资。
   - 验证：生成的医疗物资节点 lineage 为 Teladi（而非 Split）。
   - 验证：上游节点也使用 Teladi 血统。

## 3. 节点操作与转正验证 [PENDING]

### 测试目标
验证 Auto 节点转正权限、按钮布局及 Isolate/Connect 切换逻辑。

### 测试步骤
1. **按钮布局检查**: 观察任意非 T0 节点的工具栏。
   - 验证：左侧为 ✂️/🔗 (隔离/连接)，右侧为 ➕ (转正)。
2. **T0 权限检查**: 观察 T0 资源节点（如能量电池、矿石）。
   - 验证：候选区中这些产物**没有** `+` 按钮。
   - 验证：规划区中自动生成的 T0 节点**没有** ➕ (转正) 按钮。
3. **Auto 转正**: 找到一个自动生成的虚线节点（例如泰拉迪船体部件的上游石墨烯）。
4. **执行转正**: 点击节点上的 ➕ 按钮。
   - 验证：节点状态变为 `manual`，连线变为实线，且 ➕ 按钮消失，替换为 🗑️ 按钮。
5. **隔离权限检查**:
   - 找到一个手动拖入的节点，但其尚未被任何下游消费。
   - 验证：该节点工具栏中**不显示** ✂️/🔗 按钮。
   - 建立下游依赖后。
   - 验证：✂️/🔗 按钮出现。

## 4. 彻底清理逻辑验证 [PENDING]

### 测试目标
验证节点随下游消费消失而自动清理的逻辑，尤其是已隔离节点。

### 测试步骤
1. **建立依赖并隔离**: 
   - 规划“船体部件” -> 自动生成“石墨烯”。
   - 将“石墨烯”提升为手动并点击“隔离”。
   - 验证：“石墨烯”现在是隔离状态（实线，EXT 标识）。
2. **删除下游**: 删除“船体部件”节点。
   - 验证：“石墨烯”节点虽然之前是隔离状态，但因为失去了所有下游消费，应被**自动删除**。
3. **T0 清理**: 验证 T0 资源在失去所有消费者后也能正常合并删除。

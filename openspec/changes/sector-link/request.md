# sector-link 需求说明

## 目标
在星区显示列表面板中提供星区间连接能力：用户可从星区项的连接图标拖拽到其他星区的链接区，创建星区之间的双向连接，并支持从任一端删除连接。

## 已确认方案（审核重点）

### 1. 连接入口与目标区
- 在每个星区项中，拖拽把手旁新增“连接图标”。
- 在星区显示列表面板内，每个星区项新增“链接区”作为连接拖拽目标。

### 2. 建链流程
- 用户从源星区连接图标发起拖拽。
- 拖拽落到目标星区链接区后，创建一条双向连接。
- 连接关系为多对多：一个星区可以连接多个其他星区。

### 3. 删除流程
- 在任一端显示的连接项上点击删除按钮，均删除该条连接。
- 删除后两端视图同步移除，底层连接数据仅保留一份事实来源，避免单端残留。

### 4. 约束与防重
- 禁止自连接（A 不可连接 A）。
- 禁止重复连接（A-B 已存在时不重复创建）。
- 连接创建与删除都通过 store 统一入口处理，保证双向一致性。

### 5. 持久化与恢复
- 连接关系随 empire 数据持久化。
- 页面刷新或重载后，连接关系可正确恢复并渲染到两端。

## 边界

### In Scope
- 星区项连接图标与链接区 UI。
- 拖拽建链交互（图标 -> 链接区）。
- 星区双向连接数据模型（多对多）。
- 任一端删除连接后全局一致删除。
- 自连接/重复连接防护与基础反馈。

### Out of Scope
- 星区连接后的自动路径规划、距离或成本计算。
- 跨实体连接（如星区到站点、站点到站点）。
- 高级可视化动画连线编辑器。

## 验收标准（DoD）
- 每个星区项可见连接图标和链接区。
- 从 A 拖拽到 B 可建立 A-B 双向连接，且 A/B 两侧均可见。
- 支持多对多连接：同一星区可同时连接多个目标星区。
- 尝试 A-A 自连接被阻止。
- 重复创建同一对连接不会产生重复记录。
- 在 A 端或 B 端点击删除均可删除 A-B 连接，并同步从两端消失。
- 刷新后连接关系保持一致且可继续删除/新增。

# 船只建造方案对比需求
## 用户界面修订（2026-11-12，优先于下方原规划的对应描述）

- “展开对比／退出对比”统一放在属性面板标题区（默认布局的中间栏），共用醒目的翠绿描边和淡色背景；不放在船只配装标题内。保留右侧方案为次级描边按钮，选择装备期间隐藏这些操作。
- 对比复用原 ShipBuildPanelStats / MetricsPanel 的双列指标、简略／详细切换和数值＋差值条形，不新增独立视觉布局。
- B 船型选择复用 A 的原 ShipBuildSelectorView，不新增弹窗、搜索列表或独立选型界面；确认只替换 B，取消保持原会话。
- B 蓝图入口与 A 共用原浮层（包含预设、保存蓝图及原操作），仅向左弹出；选择和预设只作用于操作侧，禁止两侧使用同一保存 ID。
- 保存、另存为及退出／替换保护统一复用原 SmartSaveDialog，不保留独立的对比弹窗；双侧上下文和保存成功后才继续的行为由 presenter 管理。
- 删除可见 A/B 标记及顶部编辑对象切换；点击配装面板确定内部编辑侧。保存按钮沿用“保存”，保护对话框用左／右侧方案说明对象。
- A 侧标题保持原样；右侧标题整体按原要求水平镜像，船型／蓝图入口、入口内部控件和收藏位置反向排列，文字保持正常可读；不添加 A/B 文字标记。两侧蓝图菜单项继续左对齐，右侧浮层向左弹出。


## 目标

在已有船只建造蓝图的基础上添加另一份蓝图，比较完整方案（船体与配装），允许双方独立编辑和保存，并安全返回单船模式。展开时 B 默认使用与 A 相同的具体船型（相同 shipId，不只是相同 class），按该船型的默认蓝图选择规则初始化。B 可以更换船型或载入其他蓝图；已保存方案之间禁止相同蓝图 ID，也支持不同船、不同尺寸。同一蓝图修改配装继续使用现有装备预览对比。

## 已确认方案（审核重点）

### 入口与三栏布局

- 当前蓝图名称旁提供“展开对比”；直接以 A 的 shipId 初始化 B，不要求手动先选蓝图，不重新加载 A。
- 展开对比和 B 更换船型统一使用：筛选目标 shipId 的已保存蓝图，排除 A 当前蓝图 ID，按 createdAt 降序选择最新创建的候选；没有候选才创建目标船型的空配装。不得按 lastUpdated 排序，不包含内置预设。createdAt 相同时按蓝图 ID 升序稳定选择。
- B 初始化后为 clean：载入已有蓝图时绑定其保存目标与基线，后续普通保存更新该记录；无候选创建空配装时无保存目标，首次保存走另存为。确认编辑后按实际变化计算 dirty，保存资格与 dirty 分开判断。
- B 面板提供“更换船型”和“载入蓝图”：前者选择具体船型并按上述规则载入最新创建的可用蓝图、无候选才创建空配装，后者载入所选已保存蓝图及其船型、配装。均只作用于 B。
- 单船布局：船只 A、属性、建造材料。
- 默认对比布局：船只 A、共用属性对比、船只 B。B 占用原建造材料栏，对比期间不显示建造材料。
- A 选择装备：船只 A、A 装备选择器、共用属性对比；暂时隐藏 B 船只面板。
- B 选择装备：共用属性对比、B 装备选择器、船只 B；暂时隐藏 A 船只面板。
- 始终只有三个逻辑栏位和一个共用属性面板，同时只打开一侧选择器。隐藏面板不销毁工作副本，修改期间仅比较操作侧修改前后。
- 确认或取消装备选择后恢复默认对比布局。装备自身详情位于选择器区域内，不增加第四栏。

### 右侧船只面板镜像

- 以当前 `ShipBuildPanelFit` 的实际结构为基准：A 保持现有布局，B 面板内部水平镜像；不将竖排分类改成横排，不新增独立“更换装备”按钮，仍点击装备卡片进入选择器。
- B 头部的船型入口与蓝图入口左右对调；入口内部的文字、分隔线、图标以及收藏按钮按位置镜像，蓝图展开箭头朝左，文字和图标本身保持正常可读。
- 装备分类竖栏从左侧移到右侧，E/R/S/W/T/C/U 从上到下的顺序保持不变。
- 内容区的连接／分组按钮、槽位标签水平顺序反转并靠右；兼容性信息和装备卡片文本右对齐。装备名称、槽位编号及其数据含义不改变。
- 装备卡片数量从右侧移到左侧；数量滑条从右向左增长，最小值在右、最大值在左，数值范围、步长和提交行为保持一致。
- 默认对比和 B 选择装备时均保持 B 镜像；共用属性面板与装备选择器不随 B 整体镜像，A/B 标识、数值阅读方向和 B − A 差值方向不变。
- 返回单船后恢复普通配装布局，即使保留的是 B，也不保留镜像。C/U 本次仅确认分类入口位置，不扩展仓储子面板内部的镜像设计。

### 属性与上限

- 两侧分别使用各自船体、连接配装及现有计算规则计算属性，不将 B 的装备套入 A 的船体。
- 覆盖现有整船属性面板支持的基础、护盾、火力、速度与机动、容量等指标，保留简略／详细模式。
- 共用面板明确显示 A、B 数值和差值；差值固定为 B − A，不随编辑对象或面板位置改变。
- `class` 指 `ship_s / ship_m / ship_l / ship_xl` 尺寸等级，不是 `type` 舰种。
- 每项属性的刻度上限为 `max(defaultMaxes[A.class][字段], defaultMaxes[B.class][字段])`，经相同单位转换后使用。实际属性值不参与确定上限，不按筛选结果重新统计。
- 槽位数量如纳入展示，使用双方 class 的 `ship_slots` 对应类型与装备尺寸默认最大数量取高，不能用实际槽位数决定刻度。
- 有效零值与缺失数据区别显示；缺失值显示 `—`，不伪装成零。两侧有效默认上限均为零时不画比例条；缺失任一侧默认上限时保留数值、标明刻度不可用，不用实际值兜底。
- 实际值超过默认上限时数值和差值保持真实，条形裁剪在容器内，不抬高上限。优劣颜色按指标方向判断，延迟／充能时间等越小越好的指标不能按正差值统一标绿。
- 修改配装期间属性区只比较操作侧修改前工作副本与修改后预览，复用单船预览界面；另一侧不参与此次比较。隐藏展开／退出对比和保留另一侧操作。预览不修改工作副本、不写入保存记录、不产生 dirty；确认或取消后恢复双方对比及操作按钮。

### 双蓝图编辑与全局保存

- A、B 各自持有独立工作副本、保存目标、保存基线和 dirty 状态，禁止共享可变对象。
- 顶部保留全局保存和另存为，增加“编辑对象 A/B”选择；对比刚开启时编辑对象为 A。
- 点击某侧配装面板或操作该侧装备自动激活该侧；点击属性对比区不切换编辑对象。
- 全局按钮明确显示“保存 A”或“保存 B”，只保存当前编辑侧；两侧名称各自显示未保存标记。
- 另存为只更新该侧的保存身份和基线，不重载另一侧；普通保存不清除另一侧 dirty。
- 装备选择器打开期间禁用全局保存／另存为及对应快捷键；必须先确认或取消预览。此时不得直接切换编辑侧、替换蓝图或退出对比而绕过选择器结束流程。
- 保存对话框绑定打开时的侧和工作副本身份，不能因后续编辑对象变化写到另一侧；保存失败或取消命名时保留工作副本与 dirty。
- 禁止 A、B 对比同一蓝图，以蓝图 ID 判断，不按名称、船体或配装内容判断。B 载入蓝图的列表禁用 A 当前蓝图并说明原因，提交入口再次校验；拒绝时保留原状态，不自动创建副本或触发另存为。A 有未保存配装修改仍视为原蓝图。默认选取候选也排除 A；无候选时 B 是独立未保存方案。同船型不等于同蓝图。
- 未命名方案、内置预设派生方案沿用另存为语义；B 的“载入蓝图”入口选择已保存蓝图，“更换船型”入口选择游戏船型。

### 返回单船与替换 B

- 共用对比标题提供“退出对比”，默认保留 A；B 标题提供“更换船型”和“载入蓝图”。另提供次级操作“保留 B，返回单船”。
- 关闭侧没有修改：直接完成。关闭侧有修改：提供“保存该侧并继续”“放弃该侧修改并继续”“取消”。退出时文案明确“保存 B 并退出”等实际对象与动作。
- 保存并继续只有保存成功后才能关闭；若需要另存为，完成命名及保存后才继续。失败或取消时保持原对比会话。
- 保留侧的未保存修改原样保留，不自动保存。保留 B 时将 B 工作副本、身份与保存基线完整提升为单船对象，不能从磁盘重载 B。
- 更换 B 船型或载入蓝图都检查旧 B 的修改；先选定有效候选，再执行保存／放弃／取消保护，成功后才替换。取消选择或保护对话框保留旧 B。更换为当前船型不清空现有配装，不作为重置入口。
- 退出后恢复建造材料栏，材料按保留方案计算，编辑对象恢复单船语义。

### 生命周期与保护范围

- 对比会话不新增刷新恢复／自动保存功能；只有显式保存的蓝图进入现有持久化结构。
- 保持现有单船使用习惯；新建、加载、删除或版本切换等会使会话失效的现有操作，必须检查所有将被丢弃的工作副本，不能只检查当前编辑侧。
- 已保存目标被删除后，该侧修改不得覆盖其他记录；后续保存明确转为另存为。切换编辑侧本身不修改持久化活动身份。
- 窄屏沿用响应式能力呈现同样三个逻辑区域及相同顺序，不新增第二个属性面板。

## 边界

### In Scope

双方案临时编辑会话、固定三栏状态切换、完整属性对比与共享默认刻度、装备预览隔离、全局保存定向、逐侧 dirty 与保存身份、退出／替换保护、相关单船回归、多语言与稳定 UI 标识。

### Out of Scope

同一蓝图自对比及自动复制已有配装、多于两份方案对比、对比会话持久化／刷新恢复、自动保存、保存全部按钮、建造材料对比、新增属性计算公式、按舰种重算默认上限、拖拽交互、全仓库架构重构。本轮只生成规划文档，不修改源码或运行时测试。

## 验收标准（DoD）

1. 展开对比或 B 更换船型时，载入目标 shipId 下排除 A 后 createdAt 最新的已保存蓝图，无候选才创建空配装；A 未保存修改保留。B 初始 clean，已有记录可普通保存，空配装首次另存为。支持跨 class，取消不改变原方案。
2. 默认、A 选择、B 选择三种布局严格符合三栏顺序；修改时比较当前侧修改前后，隐藏侧保留状态但不参与此次比较。B 头部、竖栏、标签、对齐、数量与滑条按镜像规则显示，文字正常阅读，返回单船恢复普通布局。
3. 双方独立计算；差值固定 B − A；逐项上限严格取双方 class 默认值的较大值，零、缺失、超限有明确呈现。
4. 候选预览只改变操作侧展示，取消恢复，确认只改变该侧工作副本。
5. 全局保存／另存为及快捷键按明确侧路由，选择器期间不可保存预览；保存一侧不影响另一侧内容与 dirty。
6. B 载入蓝图拒绝与 A 相同的蓝图 ID，A 有未保存修改也不例外；拒绝不改变现有会话。同船体不同蓝图 ID 仍允许对比。
7. 退出、保留 B 和替换 B 均按关闭侧 dirty 执行保存／放弃／取消，失败与取消不丢失数据。
8. 单船恢复保留工作副本与材料计算，现有会话失效入口不漏检另一侧修改。
9. 新方案遵守 `store → presenter → vue`，无新增中间层或 sequential fallback；后续实施完成 focused Unit 与生产构建。

## 未决项

无阻塞项。上述异常与生命周期细则作为本方案的完整性约定，具体文案与样式在实施时沿用项目惯例。

### 默认名称补充（2026-11-12）
未命名方案默认使用当前配装状态加序号（如“高配 1”“高配 2”），不拼接船型。空配／低配／中配／自定义同样编号；从 1 起跳过所有已保存蓝图中占用的名称。已有方案名称保持原样。同步检查名称展示入口，仅报告本次命名调整带来的识别风险。

### 蓝图删除与高亮补充
当前侧强高亮、另一侧弱高亮；禁止删除另一侧正在使用的已保存蓝图，无对应保存记录则不限制。删除当前侧保留配装并恢复未命名的自定义状态，取消全会话删除保存保护。

### 已保存蓝图与未保存预设的状态规则
沿用 archive/2026-03-09-blueprint-preset/request.md 的原规则：已有保存目标时，选择高配等预设仅应用配装，保留蓝图名称、身份和当前蓝图高亮。相对保存基线有实际变化时显示红点，无变化时不显示；保存更新原记录。没有保存目标（包括删除当前蓝图后）再选高配，才显示并高亮高配，未修改预设时不显示红点，下一次保存进入另存。A、B 两侧一致。

### 菜单整行高亮
蓝图配装的当前侧、另一侧及悬停高亮覆盖完整行，包括名称、收藏与删除按钮区域，宽度与同一菜单的默认配装行一致，不因名称短而收缩。

### 同一大类型下切换具体槽位
“大类型”指 E／R／S／T／C／U 入口，保持其现有切换和关闭选择器行为。当前侧选择器已打开时，允许直接点击同一大类型下的另一具体槽位（如引擎→附属护盾），不要求先确认或取消。丢弃旧槽位未确认预览，更新槽位高亮、候选、装备详情和修改前后属性；确认只应用新槽位。A、B 一致，仍禁止跨侧切换。

### 切换槽位的默认装备
直接切换具体槽位后，默认选中该槽位当前已安装装备，不沿用上一槽位未确认候选，也不得误置为空装备。原本为空的槽位仍选空装备。A、B 一致。

### 装备属性对比位置
修改配装时，原装备属性对比面板位于舰船属性上方，不放到候选列表下方。修改 A 时位于右栏，修改 B 时位于左栏；显示当前装备与所选候选的属性。

### 两侧配装标题保存入口
配装名称按钮框内新增独立保存图标：A 为“保存图标／名称／箭头”，B 镜像为“箭头／名称／保存图标”，文字及保存图标本身不翻转。点击图标只保存所在侧、不展开菜单；未保存方案进入原命名弹窗。两侧菜单增加分隔的“另存为”，只针对所在侧并复用 SmartSaveDialog。原 dirty、命名及保护语义保持，装备选择期间禁用保存入口。

### 另存为的新名称
已有蓝图另存为默认提供不同且未占用的名字，保留名称主体，以数字序号避开所有已有蓝图和当前工作名称。例如“高配 1”另存时，若“高配 2”已存在则建议“高配 3”，不生成“高配 1 1”。A／B 及保护弹窗内另存为共用规则，原记录名称不修改。

### 删除确认使用站内弹窗
蓝图删除不再调用浏览器 confirm／alert，改用与另存为一致的深色遮罩、标题、内容及底部按钮布局。弹窗显示蓝图名称，提供取消及删除；确认前不删除，另一侧正在使用的蓝图仍禁止删除。

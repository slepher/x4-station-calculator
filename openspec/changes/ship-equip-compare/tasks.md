# 实施任务

本清单为后续 `/x4:apply ship-equip-compare` 使用；实施进度见下方勾选及 implementation.md 的验证记录。每项行为变更必须连同其 focused Unit 在同一任务中实现并运行，测试文件只放在 `tests/unit/**`。E2E 文档、实现和运行另走 `/x4:e2e-test ship-equip-compare`，不属于本清单。

## 1. 双方案领域上下文与计算

- [x] 1.1 在船只建造 store 中建立独立 A/B 工作上下文及明确保存目标、快照和预设状态，保留现有单船入口语义；展开及 B 换船型统一按目标 shipId 筛选非 A 的已保存蓝图，以 createdAt 降序、ID 升序选择首个候选，无候选才创建空配装，不重载 A；两分支均 clean，已有记录绑定保存目标，空配装首次另存为；载入蓝图入口拒绝与 A 相同 ID，不复制原方案。
  - 同任务 Unit：深层 connections/storage 引用隔离；A dirty 在加入 B 前后不变；默认 B 精确匹配 shipId；排除 A 后选择 createdAt 最新而非 lastUpdated 最新；同时间 ID 稳定排序；无候选（含仅有 A）为空配装；两分支 clean 与保存资格；同 ID 被拒绝且 A 未保存配装修改不改变判断；同船体不同 ID 允许；不存在 B 时拒绝 B 操作；新建方案的保存资格与 dirty 独立。
- [x] 1.2 将现有整船属性计算从 Vue 移到 store 领域能力，显式以各自船体和蓝图计算；fit/equipment 编辑、装备资格、DLC 与查询使用对应方案上下文，不交换全局 blueprint 来复用计算。
  - 同任务 Unit：不同船体质量／阻力／连接数量的 A/B 独立结果；同船体不同蓝图的配装；对应侧 DLC 资格；现有单船指标计算保持一致。
- [x] 1.3 支持指定侧的纯预览和正式赋值，沿用 connection/group 分配及 shield key 规则。
  - 同任务 Unit：双方预览不修改工作副本、保存记录与 dirty；取消丢弃预览；确认只改变操作侧目标连接；group 数量与 shield 映射保持现有语义。

## 4. 全局保存与身份保护

- [x] 4.1 保存／另存为显式接受方案上下文，复用现有蓝图库存储；写入成功后才更新对应侧身份、保存基线与活动持久化 ID，不重载任何另一侧上下文。
  - 同任务 Unit：保存 A/B 只影响该侧；两侧 dirty 同时存在；另存为更新一侧 ID 且无可变引用共享；模拟存储失败时 dirty 与工作副本保留；成功保存活动 ID 与记录一致。
- [x] 4.2 接通全局工具栏和快捷键到当前编辑侧，检查保存资格；picker 时禁用保存／另存为；命名对话框捕获侧与会话身份并校验。
  - 同任务 Unit：按钮与快捷键路由一致；禁止保存预览；弹窗焦点变化不转存另一侧；会话身份失效拒绝提交；命名取消不修改基线。

## 5. 退出、替换与会话生命周期

- [x] 5.1 实现按关闭侧进行 dirty 保护的退出意图，支持保留 A／保留 B，保存成功才关闭；提升 B 时迁移完整工作上下文并恢复材料与单船编辑状态。
  - 同任务 Unit：关闭侧 clean 直接退出；dirty 保存／放弃／取消；保存失败与另存为取消保持对比；关闭侧与 activeSide 不同；保留侧未保存修改和基线不变；B 提升不从存储重载；材料输入指向保留方案。

  - 同任务 Unit：取消候选、取消保护、保存失败均保留旧 B；成功替换不影响 A；换船型不带旧 B 配装；不同船型也按 createdAt 选最新、无候选为空配装；已有记录普通保存与空配装首次另存为；选择当前船型不重置；载入蓝图恢复该记录的船体与配装；新 B 与 A 同 ID 时拒绝且保留旧 B，不创建副本或触发另存为。
- [x] 5.3 审查并接通新建、加载、删除、版本切换等会话失效入口，区分全会话 dirty 与编辑侧 dirty；收集所有将丢弃对象，固定 A→B 保护流程。
  - 同任务 Unit：只有隐藏侧 dirty 时也受保护；两侧 dirty 的逐侧处理；任一步取消阻止切换；此前已成功保存无需回滚；删除保存目标不导致覆盖其他记录；非破坏性编辑侧切换不触发丢弃保护。

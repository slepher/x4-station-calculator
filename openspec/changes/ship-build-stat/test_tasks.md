- 子弹数据: damage=7000, lifetime=1.75, shotHeat=6500, heat=2000, ammo=1
- 武器heat: overheat=10000, cooldelay=0.13, coolrate=500
- singleDamage = 7000 × 1.75 = 12250
- singleShotTime = 0 + max(1.75, 2.05) = 2.05
- singleHeat = 6500 + 2000 × 1.75 = 10000
- avgShotTime = 2.05
- burstDPS(单武器) = 12250 / 2.05 = 5975.6 MW
- burstDPS(4武器) = 5975.6 × 4 = 23902.4 MW
- avgHeatPerSec = 5975.6 / 12250 × 10000 = 4878.05
- timeToOverheat = 10000 / 4878.05 = 2.05s
- cycleTime = 2.05 + 0.13 + (10000 / 500) = 22.18s
- sustainedDPS(单武器) = 5975.6 × (2.05 / 22.18) = 552.2 MW
- sustainedDPS(4武器) = 552.2 × 4 = 2208.8 MW

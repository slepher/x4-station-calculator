# x4-map-resource 需求说明

## 目标
为 map 页面增加右上角资源筛选面板，支持按资源组合与最低丰度快速筛选星区，并提供按资源丰度总分排序的命中候选列表。
该能力需要与现有左上角 sector 搜索共存，避免高亮和选中语义冲突。

## 已确认方案（审核重点）

### 1. 入口与整体布局
- map 页面右上角新增常驻资源筛选面板。
- 面板与左上角搜索框形成左右对称布局，不使用关闭按钮。
- 面板自上而下包含三块：
  - 资源多选 tag 区
  - 已选资源配置区
  - 命中候选框

### 2. 资源选择与配置
- 资源列表参考 `regionyields.json`，覆盖 `ore / silicon / ice / nividium / hydrogen / helium / methane / rawscrap`。
- UI 文案中 `rawscrap` 显示为 `Scrap`，内部仍映射到 `rawscrap`。
- tag 支持多选，筛选语义为 `AND`。
- 每个已选资源都可以独立设置最低丰度。
- 新选中资源时，默认最低丰度为 `lowest`。
- 当已选资源数量大于 `2` 时，配置区顶部额外显示 `所有项` 控件。
- 调整 `所有项` 下拉时，需要同步更新当前全部已选资源的最低丰度。

### 3. 丰度来源与判定规则
- 丰度等级顺序以 `regionyields.json` 中每个资源自身的 `yields[].name` 顺序为准。
- 星区实际资源命中与排序数据以 `maps.json` 中 sector 的 `resources[]` 为准。
- 资源是否满足门槛，按 sector 对应资源的 `yield` 与已选资源最低丰度比较判定。
- 某 sector 若缺少任一已选资源，则该 sector 不命中。

### 4. 命中候选框
- 资源配置区下方显示命中候选框。
- 仅当至少选中一个资源时显示命中候选框。
- 候选列表只显示同时满足全部已选资源及其最低丰度的 sector。
- 候选按“已选资源在该 sector 中的 `level` 总和”从高到低排序。
- 最多显示 `10` 个候选。
- 点击候选后的行为与左上搜索框命中结果点击一致：聚焦并选中对应 sector。

### 5. 搜索与资源筛选并存策略
- 采用方案 A：搜索与资源筛选为独立双通道。
- 左上搜索结果不被资源筛选强制裁剪。
- 右上命中候选框只反映资源筛选结果。
- 地图渲染时区分三类状态：
  - 当前选中 sector
  - 搜索命中高亮
  - 资源筛选命中高亮
- 高亮优先级为：当前选中 > 搜索命中 > 资源命中。
- 当某 sector 同时命中搜索与资源筛选时，主样式以搜索高亮为准，并允许叠加较弱的资源提示。

## 边界

### In Scope
- map 页面右上资源筛选面板。
- 资源 tag 多选与已选资源独立最低丰度下拉。
- 已选资源超过 `2` 个时的 `所有项` 批量设置控件。
- 资源命中候选框、排序规则与点击聚焦行为。
- 搜索高亮与资源高亮的分层共存规则。

### Out of Scope
- 修改左上搜索框的匹配规则与候选排序逻辑。
- 为资源筛选结果增加分页、收藏或持久化方案。
- 引入新的地图数据源或重写 sector 布局算法。
- 改造整个 map 页视觉主题。

## 验收标准（DoD）
- map 页面右上角存在常驻资源筛选面板，且无关闭按钮。
- 资源 tag 支持多选，语义为 `AND`。
- 每个已选资源都能单独设置最低丰度，默认值为 `lowest`。
- 当已选资源数量大于 `2` 时，出现 `所有项` 下拉，并能同步修改全部已选资源的最低丰度。
- 只有同时满足全部已选资源及其最低丰度的 sector 才会进入命中候选。
- 命中候选按命中资源 `level` 总和降序排序，最多显示 `10` 个。
- 点击命中候选后，地图聚焦并选中对应 sector，行为与搜索结果点击一致。
- 搜索与资源筛选可同时存在，左上搜索结果不被资源筛选强制裁剪。
- 地图高亮优先级明确：当前选中 > 搜索命中 > 资源命中。

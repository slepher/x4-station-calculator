# user-save-poi Change Request

## 目标

将存档中的兴趣点（空间站、保险箱、弃船等）完整整合到地图工作台，包括分类导航、可见性控制、坐标列表、地图 POI 渲染、tooltip 与命名规则。

## 已确认方案（审核重点）

### 1. POI 导航层级

- `savePanel` 中 POI 流程采用两层子页面：
  - 分类菜单
  - 坐标列表
- 进入 POI 分类页时，二级面包屑仅显示存档名。
- 分类页仅作为导航入口，不再承担 binding 职责。

### 2. 分类与可见性控制

- 分类菜单显示 7 个 POI 分类。
- 分类菜单仅显示分类名称、数量与进入详情的箭头按钮，不再内嵌 checkbox。
- 地图右上角提供独立的 POI 可见性折叠菜单。
- checkbox 默认全不选。
- 未勾选类别进入详情时，地图临时显示该类别；返回分类层后取消临时显示，但不改 checkbox 状态。

### 3. 坐标列表

- 坐标列表按星区分组显示。
- 提供搜索框筛选星区名。
- 点击坐标项后，地图平移/缩放到对应兴趣点。

### 4. 地图 POI 渲染

- 地图上渲染 save POI 覆盖层。
- 各分类使用不同颜色与图标语义。
- 初期支持 code/名称、图标、focus、高亮与 tooltip。
- 右上角可见性控制仅影响 POI 层，不影响 binding POI。

### 5. Tooltip 与命名

- 列表、地图 POI 与 tooltip 使用统一数据源与统一命名解析。
- 空间站按 `productionProfile`、`tag`、`is_headquarter` 解析显示名称。
- 弃船按 `class + purpose` 显示图标与 tooltip 名称。

## 边界

### In Scope

- 分类菜单
- 右上角 POI 可见性控制
- 坐标列表、搜索与 focus
- 地图 POI 覆盖层、tooltip、命名与图标规则

### Out of Scope

- 存档首页的 guid 外容器交互
- binding 的 Step 1/2/3 工作流
- binding POI 的常驻显示与拖拽规则

## 验收标准（DoD）

1. 用户可以从存档首页进入 POI 分类页，并看到仅用于导航的分类菜单。
2. 地图右上角可见性控件可以控制 7 类 POI 的显示。
3. 未勾选类别进入详情时，地图会临时显示该类别；返回后恢复未显示。
4. 坐标列表支持按星区分组和搜索筛选。
5. 点击坐标项可使地图聚焦到对应 POI。
6. 地图 POI 与 tooltip 使用统一命名规则和统一 overlay 数据。
7. 空间站与弃船图标规则、tooltip 规则保持一致。

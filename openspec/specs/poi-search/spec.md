## Requirements
### Requirement: 搜索控件UI

用户 SHALL 可通过搜索控件选择类别、输入内容、添加搜索条件。

#### Scenario: 选择搜索类别

**前提** 用户打开势力空间站POI列表页面

**当** 用户点击类别下拉框

**那么** 显示三个选项：产品、模块、势力

**并且** 默认选中"产品"类别

#### Scenario: 输入搜索内容

**前提** 用户已选择"产品"类别

**当** 用户在输入框输入"能源"

**那么** 显示产品自动完成建议列表

**并且** 建议列表只包含产品名称中包含"能源"的商品

**并且** 建议列表最多显示10条结果

#### Scenario: 选择建议项添加药丸tag

**前提** 自动完成建议列表显示"能源电池"

**当** 用户点击"能源电池"建议项

**那么** 输入框内容清空

**并且** 药丸tag区域显示新tag：`产品:能源电池`

**并且** 空间站列表立即过滤，只显示包含能源电池输出的空间站

#### Scenario: 删除药丸tag

**前提** 药丸tag区域已存在 `产品:能源电池`

**当** 用户点击该tag的删除按钮（×）

**那么** 该tag从药丸区域移除

**并且** 空间站列表立即重新过滤

### Requirement: 自动完成搜索范围

自动完成建议列表 SHALL 只搜索当前选定类别的数据源。

#### Scenario: 产品类别只搜索产品

**前提** 用户选择"产品"类别

**当** 用户输入"energy"

**那么** 建议列表只从 `waresMap` / `localizedWaresMap` 搜索

**并且** 不显示模块或势力建议

#### Scenario: 模块类别只搜索模块

**前提** 用户选择"模块"类别

**当** 用户输入"plasma"

**那么** 建议列表只从 `modulesMap` / `localizedModulesMap` 搜索

**并且** 只显示有输出的生产模块（`type === 'production' && outputs 非空`）

**并且** 不显示产品或势力建议

#### Scenario: 势力类别只搜索势力

**前提** 用户选择"势力"类别

**当** 用户输入"argon"

**那么** 建议列表只从 `factions` 搜索

**并且** 不显示产品或模块建议

### Requirement: 药丸tag分组逻辑

药丸tag SHALL 分为两组，组内 SHALL 为 OR，组间 SHALL 为 AND。

#### Scenario: 产品tag组内OR

**前提** 药丸区域已添加 `产品:能源电池` 和 `产品:食品`

**当** 空间站列表过滤

**那么** 显示任意匹配一个产品的空间站（OR逻辑）

**并且** 包含能源电池输出的空间站显示

**并且** 包含食品输出的空间站显示

**并且** 同时包含两个产品的空间站也显示

#### Scenario: 产品+模块组内OR

**前提** 药丸区域已添加 `产品:能源电池` 和 `模块:等离子导体生产线`

**当** 空间站列表过滤

**那么** 显示任意匹配产品或模块的空间站（OR逻辑）

**并且** 包含能源电池输出的空间站显示

**并且** 包含等离子导体模块的空间站显示

#### Scenario: 势力tag组内OR

**前提** 药丸区域已添加 `势力:argon` 和 `势力:teladi`

**当** 空间站列表过滤

**那么** 显示 owner 为 argon 或 teladi 的空间站（OR逻辑）

#### Scenario: 产品组与势力组间AND

**前提** 药丸区域已添加 `产品:能源电池` 和 `势力:argon`

**当** 空间站列表过滤

**那么** 显示既包含能源电池输出 AND owner 为 argon 的空间站

**并且** 包含能源电池但 owner 不是 argon 的空间站不显示

**并且** owner 是 argon 但不包含能源电池的空间站不显示

### Requirement: 空间站匹配规则

搜索条件与空间站数据的匹配规则 SHALL 遵循以下约定。

#### Scenario: 产品匹配module.outputs

**前提** 空间站数据包含 modules 数组

**当** 过滤 `产品:能源电池`

**那么** 检查空间站任意 module 的 `outputs` 对象

**并且** 如果 `outputs` 的 key 包含 `energycells`（能源电池wareId），则匹配成功

#### Scenario: 模块匹配module.ref或module_id

**前提** 空间站数据包含 modules 数组

**当** 过滤 `模块:等离子导体生产线`

**那么** 检查空间站任意 module 的 `ref` 或 `module_id`

**并且** 如果 `ref` 或 `module_id` 匹配等离子导体模块ID，则匹配成功

#### Scenario: 势力匹配station.owner

**前提** 空间站数据包含 owner 字段

**当** 过滤 `势力:argon`

**那么** 检查空间站的 `owner` 字段

**并且** 如果 `owner === 'argon'`，则匹配成功

### Requirement: 搜索条件状态管理

搜索条件状态 SHALL NOT 持久化，每次打开页面 SHALL 为空白。

#### Scenario: 打开页面无搜索条件

**前提** 用户首次打开势力空间站POI列表页面

**当** 页面加载完成

**那么** 药丸tag区域为空

**并且** 类别下拉框默认选中"产品"

**并且** 输入框为空

#### Scenario: 切换类别不影响已添加tag

**前提** 药丸区域已添加 `产品:能源电池`

**当** 用户将类别下拉框切换为"模块"

**那么** 已添加的 `产品:能源电池` tag保留

**并且** 输入框清空

**并且** 用户可继续添加模块tag
